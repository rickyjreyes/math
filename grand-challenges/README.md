## Research standards

1. Define the exact model, domain, topology, parameters, and quantifiers.
2. Check existing literature and prove or refute elementary special cases.
3. Search for explicit counterexamples before stating universal claims.
4. Separate analytic proofs, kernel-checked Lean results, numerical evidence, and physical interpretations.
5. Link each challenge to a precise theorem statement and an actionable first milestone.
