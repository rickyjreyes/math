# GC43: What can a physically constrained wave-cell automaton compute?

**Plain-language question:** Can a simple, local, phase-carrying rule simulate arbitrary computation without hiding an ordinary computer inside the model?

**Status:** Candidate **constrained computational universality** question. Unrestricted one-dimensional cellular automata can already be universal. A new result must depend on precisely stated additional constraints.

## Freeze a mathematical model before claiming universality

A cellular automaton consists of a finite alphabet $A$ and a radius-one local rule $F:A^3\to A$, inducing the global synchronous map

\`\`\`math
(\mathcal F(x))_j=F(x_{j-1},x_j,x_{j+1}),
\qquad x\in A^{\mathbb Z}.
\`\`\`

A proposed *wave-cell subclass* must explicitly specify a phase label (for example, in $\mathbb Z/4\mathbb Z$), an amplitude/occupancy label, the admissible backgrounds, and which invariants the rule must preserve. **These additional restrictions are currently part of the problem specification, not verified properties of an existing machine.**

A useful concrete candidate class is $A=(\mathbb Z/4\mathbb Z)\times\{0,1\}$ with translation-invariant radius-one local rules whose global maps are reversible and preserve total occupancy for configurations that differ from a fixed zero-occupancy background at finitely many sites. If this class is empty or trivial under the stated assumptions, that is a meaningful obstruction; the definition can then be revised transparently.

## Exact research question

Is there a **single explicitly specified rule** in the frozen constrained class, together with a **uniform encoding** of an arbitrary Turing machine $M$ and input $w$, whose iteration simulates the machine with polynomial time and space overhead relative to a stated TM cost model? Alternatively, prove that no rule in that class can satisfy such a simulation.

Define how machine descriptions, blank tape, halting and output decoding are encoded. Include a bijective decoder where claimed and a precise accounting of initialization overhead, simulation depth and occupied spatial extent.

## Mandatory novelty check

Matthew Cook proved universality for **Rule 110**, an elementary radius-one cellular automaton. Thus "some radius-one finite-alphabet cellular automaton is universal" is already known and **must not be advertised as new**. The challenge is the mathematical impact of extra reversibility, conservation and phase constraints, if any, and the accuracy of a uniform polynomial simulation.

This is a **discrete mathematical** question. It neither establishes practical photonic hardware nor demonstrates a PDE-to-automaton physical implementation.

## First falsifiable milestones

1. Publish the complete transition table $F$ and a program that checks reversibility and conserved occupancy for bounded test systems, explicitly labeling these only finite tests.
2. Prove one nontrivial encoding invariant or show that the candidate constraints forbid required transport/interaction behavior.
3. Give an explicit uniform compiler/decoder and prove a faithful step-simulation lemma.
4. Prove polynomial overhead for the declared cost model; inspect whether known universal reversible/conservative automata already satisfy the same constraints.

## Initial literature leads

- Cook (2004), [*Universality in Elementary Cellular Automata*](https://doi.org/10.25088/ComplexSystems.15.1.1).
- Cook (2009), [*A Concrete View of Rule 110 Computation*](https://arxiv.org/abs/0906.3248).

**Resolution:** A fully specified constrained local rule with proved polynomial universal simulation, or an impossibility theorem for the precisely frozen rule class. Claims about physical wave computation require a separate experimental argument.
