# E61 — Exact continuum pattern-formation threshold

[PDF](paper.pdf) · [LaTeX source](../../papers/e61-pattern-formation-threshold/main.tex)

Proves the centered linear Swift--Hohenberg threshold \(r_c=0\) on \(\mathbb{R}^d\), including the spectral and semigroup stability classification, unstable Fourier band, and finite-periodic-domain threshold. Distinguishes the centered parameter from the uncentered E12 parameter.

Research manuscript; not independently peer-reviewed. Lean-formalized in full ([E61Certification](../../lean/MathProofs/E61Certification.lean) on [SwiftHohenbergL2](../../lean/MathProofs/SwiftHohenbergL2.lean); `ReyesMath.E61Cert.theorem_e61`; see the [certification report](../../docs/ANALYTIC_CERTIFICATION_2026-10-30.md) and [lean/formalization.yaml](../../lean/formalization.yaml)).
