# E69 — Bounded corrected regularized curvature

[PDF](paper.pdf) · [LaTeX source](../../papers/high-regularity-bounded-curvature-e69/main.tex)

Analytic proof: for fixed epsilon > 0 and s > n/2 + 2, the corrected modulus-squared curvature operator maps an H^s(R^n; C) field to L-infinity. Includes a uniform bound on the regularized reciprocal even at field zeros. This is not a claim of Lean formalization, PDE well-posedness, dynamical stability, or peer review.
