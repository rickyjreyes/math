# E68 — Localized gradient-energy estimate

[PDF](paper.pdf) · [LaTeX source](../../papers/localized-gradient-energy-e68/main.tex)

Manuscript 4 — WCT energy audit. Complete analytic proofs and counterexamples.

- **REFUTED:** Unrestricted \(H^1\) localized estimate for \(n>2\), using a fixed finite-energy singular field and a smooth concentration family. The all-radius \(n=1\) form also fails.
- **PROVED:** \(n=2\) case, with constant \(C=1\).
- **PROVED:** Corrected bound for \(n>2\) under \(\nabla\psi\in L^n\), with explicit \(\omega_n^{1-2/n}\) constant.
- **PROVED:** An \(H^2\)-based estimate in spatial dimensions 3 and 4; the same uniform estimate fails for \(n>4\).

These are analytic statements, not Lean kernel-checked. No WCT nonlinear-PDE existence, stability, or physical confinement-lifetime theorem is claimed. The [PDF build workflow](../../.github/workflows/pdfs.yml) publishes PDFs generated from this LaTeX source.
