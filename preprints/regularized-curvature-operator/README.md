# M2 + E17 — Regularized curvature operator

[PDF](paper.pdf) · [LaTeX](../../papers/regularized-curvature-operator/main.tex)

Manuscript 2 (M2/E17). Establishes pointwise strict positivity of the corrected modulus-squared denominator for every fixed regularization scale, smooth bounded regularized reciprocal, convergence to `1/ψ` off nodes, quantitative away-from-node error bounds, strong `L²` convergence under a uniform nonvanishing condition, global `U(1)` invariance, and a counterexample to the old complex denominator. Analytic proof, Lean-formalized in full ([E17Certification](../../lean/MathProofs/E17Certification.lean), `ReyesMath.E17Cert.main_theorem`; see the [certification report](../../docs/ANALYTIC_CERTIFICATION_2026-10-30.md) and [lean/formalization.yaml](../../lean/formalization.yaml)); not peer reviewed.

This is an operator-level theorem, not a nonlinear PDE existence, uniqueness, or stability result. PDFs are compiled from the LaTeX source by the repository's [build script](../../scripts/build_pdfs.sh) and [workflow](../../.github/workflows/pdfs.yml).
