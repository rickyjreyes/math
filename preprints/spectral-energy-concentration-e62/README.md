# E62 — Spectral energy concentration fraction

[PDF](paper.pdf) · [LaTeX source](../../papers/spectral-energy-concentration-e62/main.tex)

Family: F11. Manuscript 1 — Self-Emergent Fourier Cymatics.

Proves that for a nonzero square-integrable field, the Fourier-energy fraction contained in an arbitrary set of selected modes is in [0,1], including sharp equality conditions. Independent orthogonal-projector proof and continuous-spectrum extension included. The quotient is undefined at zero total energy; this theorem does not imply any dynamical mode selection or monotone concentration.
