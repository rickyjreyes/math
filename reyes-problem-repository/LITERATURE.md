## How to extend this ledger

For each paper record the exact equation or machine, parameter range, boundary conditions, function spaces, known theorem, and **specific logical difference** from the proposed GC statement. Mark the date and whether an original full text, abstract, or a secondary source was inspected. Never infer an open problem from an incomplete citation search.

In particular, the cited sources are historical mathematical context and **do not** certify new Wave Confinement Theory predictions.
