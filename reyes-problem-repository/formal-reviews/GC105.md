## Canonical mathematical statement

**Model freeze.** Fix $H_0=(\Delta+1)^2$ on $L^2(\mathbb R^2)$, spectral value $\lambda=1$, $g\in C_c^\infty(\mathbb R^2;\mathbb C)$, and $\Gamma(g)=\lim_{\eta\downarrow0}\operatorname{Im}\langle g,(H_0-1-i\eta)^{-1}g\rangle$. Use the **unitary** 2D Fourier transform $\widehat g=(2\pi)^{-1}\int e^{-ix\cdot\xi}g(x)\,dx$.

**Precise mathematical target / proven narrower result.** The frozen coefficient has an explicit nonnegative expression: $\boxed{\Gamma(g)=\frac{\pi}{4}\int_0^{2\pi}|\widehat g(\sqrt2\,e_\theta)|^2\,d\theta+\frac{\pi^2}{4}|\widehat g(0)|^2}$. Indeed, polar integration with $t=|\xi|^2$ gives multiplier denominator $t(t-2)-i\eta$ and measure $d\xi=\frac12\,dt\,d\theta$. The ordinary circle root t=2 contributes the first term; the collapsed point t=0 is an endpoint root and contributes the **half-weight** second term. Hence $\Gamma(g)>0$ iff $\widehat g(0)\ne0$ or the restriction to the circle $|\xi|=\sqrt2$ is not identically zero. Any nonnegative nonzero compact bump g gives $\widehat g(0)>0$.

**Original scope text (preserved for comparison):**

Let $H_0=(\Delta+1)^2$ and $\lambda=1$. For $g\in C_c^\infty(\mathbb R^2;\mathbb C)$, define $\Gamma(g)=\lim_{\eta\downarrow0}\operatorname{Im}\langle g,(H_0-\lambda-i\eta)^{-1}g\rangle$, whenever finite. Characterize precisely those g with $\Gamma(g)>0$ using the Fourier restrictions to the dispersion shells $(|\xi|^2-1)^2=1$, and derive an explicit positive example.
