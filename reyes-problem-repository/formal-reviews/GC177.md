## Canonical mathematical statement

**Model freeze.** Fix real $u_t=2u-(1+\Delta)^2u-u^3$ on $\mathbb R^2$, nonconstant $2\pi$-periodic stripe $\phi(x_1)\in H^4_{\mathrm{per}}$ solving $2\phi-(1+\partial_1^2)^2\phi-\phi^3=0$. Use $L_\phi(\theta)=2-[1+(\nabla+i\theta)^2]^2-3\phi^2$ with $\theta\in[-1/2,1/2]^2$ and domain $H^4(T^2)$.

**Precise mathematical target / proven narrower result.** Characterize profiles satisfying $\sup_{\theta\ne0}\sup\operatorname{Re}\sigma(L_\phi(\theta))\le0$, including neutral translation and the small-$\theta$ Bloch expansion. The quasi-momentum is continuous because the medium is infinite periodic.

**Original scope text (preserved for comparison):**

For real $u(t,x)$ on $\mathbb R^2$, fix $u_t=2u-(1+\Delta)^2u-u^3$. Let $\mathscr S$ be the set of nonconstant real $2\pi$-periodic $H^4_{per}(0,2\pi)$ profiles $\phi(x_1)$ satisfying $2\phi-(1+\partial_1^2)^2\phi-\phi^3=0$. For each $\phi\in\mathscr S$ and $\theta\in[-1/2,1/2]^2$, let $L_\phi(\theta)=2-[1+(\nabla+i\theta)^2]^2-3\phi^2$ on $H^4(\mathbb T^2)$. Determine which profiles satisfy $\sup_{\theta\ne0}\sup\operatorname{Re}\sigma(L_\phi(\theta))\le0$ and identify the small-θ expansion.
