**Precise source target, reproduced without changing mathematical quantifiers:**

Let p=2, n≥1, and $R:\mathbb F_2^n\to\mathbb F_2^n$ be the periodic nearest-neighbor update $R(x)_i=x_i\oplus x_{i-1}$. Input a sparse multivariate polynomial $f\in\mathbb F_2[X_1,…,X_n]$ encoded by monomial/exponent lists. Decide whether $f(R(x))=f(x)$ for every $x\in\mathbb F_2^n$; classify complexity in n and input bit length.

**Requested decision.** Determine whether the exact quantified claim above holds for the specified admissible class.
