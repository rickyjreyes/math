## Canonical mathematical statement

**Model freeze.** Let $V\in C^2(\mathbb R^n)$, bounded below with compact sublevel sets, and let a global solution satisfy $x'(t)=-\nabla V(x(t))$. Take $C=\{x:\nabla V(x)=0\}$.

**Precise mathematical target / proven narrower result.** Show $\operatorname{dist}(x(t),C)\to0$ as $t\to\infty$. Because $dV/dt=-\|\nabla V\|^2\le0$ and the trajectory remains in a compact initial sublevel, every omega-limit point must be critical. This is a classical convergence-to-set theorem, not convergence to a unique equilibrium.

**Original scope text (preserved for comparison):**

Let $V:\mathbb R^n\to\mathbb R$ be C², bounded below and with compact sublevel sets. Let x(t) be a global solution of $x'=-\nabla V(x)$ with initial state x0. Prove $\operatorname{dist}(x(t),\{x:\nabla V(x)=0\})\to0$ as t→∞, provided the critical set within the initial sublevel is nonempty.
