## Canonical mathematical statement

**Model freeze.** Encode $a,b\in\{0,1\}$, let a lossless $U\in U(N)$ act on complex amplitudes and decode output bit 1 exactly when $|(Uz)_1|^2>\tau$, $\tau\ge0$. Specify whether an always-on coherent reference is included among z's inputs; thresholding is nonlinear measurement.

**Precise mathematical target / proven narrower result.** Without any reference $z=(a,b)$, $z(0,0)=0$ forces output 0 for every unitary U and nonnegative threshold, contradicting $\operatorname{NAND}(0,0)=1$. With reference $z=(1,a,b)$, choose a unitary first row $(2,-1,-1)/\sqrt6$; then $I_{00}=4/6$, $I_{01}=I_{10}=1/6$, $I_{11}=0$, and $\tau=1/12$ realizes NAND. Both statements are finite-dimensional algebra, not universal passive optical computational power or experimentally demonstrated hardware.

**Original scope text (preserved for comparison):**

Encode a,b∈{0,1} as complex coherent amplitude inputs. A passive lossless network is unitary U. Decode the first output to 1 iff $|(Uz)_1|^2>\tau$, with $\tau\ge0$.

**Without a reference beam:** for z=(a,b)∈C² and any U∈U(2), input 00 gives z=0, first output amplitude 0 and bit 0. NAND(0,0)=1. Thus no such (U,τ) can compute NAND at all four inputs.

**With one always-on reference beam:** set z=(1,a,b)∈C³ and choose any U∈U(3) whose first row is $(2,-1,-1)/\sqrt6$. This unit vector can be completed to a unitary matrix by orthonormal extension. Then the first output is $(2-a-b)/\sqrt6$. Its four detected intensities are
$$
I_{00}=4/6,\qquad I_{01}=I_{10}=1/6,\qquad I_{11}=0.
$$
Choosing $\tau=1/12$ gives exactly NAND: 1,1,1,0.
