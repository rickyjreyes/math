**Precise source target, reproduced without changing mathematical quantifiers:**

Encode a,b∈{0,1} as complex coherent amplitude inputs. A passive lossless network is unitary U. Decode the first output to 1 iff $|(Uz)_1|^2>\tau$, with $\tau\ge0$.

**Without a reference beam:** for z=(a,b)∈C² and any U∈U(2), input 00 gives z=0, first output amplitude 0 and bit 0. NAND(0,0)=1. Thus no such (U,τ) can compute NAND at all four inputs.

**With one always-on reference beam:** set z=(1,a,b)∈C³ and choose any U∈U(3) whose first row is $(2,-1,-1)/\sqrt6$. This unit vector can be completed to a unitary matrix by orthonormal extension. Then the first output is $(2-a-b)/\sqrt6$. Its four detected intensities are
$$
I_{00}=4/6,\qquad I_{01}=I_{10}=1/6,\qquad I_{11}=0.
$$
Choosing $\tau=1/12$ gives exactly NAND: 1,1,1,0.

**Frozen algebraic decision is already in its source dossier:** with zero input $(a,b)=(0,0)$ and no reference beam, a homogeneous linear unitary network outputs zero, contradicting NAND(0,0)=1 under a nonnegative positive-intensity threshold. With a powered reference amplitude and nonlinear threshold readout, the source supplies an explicit NAND construction. Neither branch certifies a fabricated passive logic gate.
