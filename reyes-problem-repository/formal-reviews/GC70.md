Let $\mathscr S_m=\{(\omega,\phi):F_\omega(\phi)=0,\ 0\ne\phi\in H^4(\mathbb R^2),\ \|\phi\|_2^2=m\}$. Determine the set of masses $m>0$ for which $\mathscr S_m$ contains a profile that is **not radial about any translated center**, even after constant phase rotation. A bifurcation is a $C^1$ curve $s\mapsto(m(s),\omega(s),\phi_s)$ in $\mathbb R_+\times\mathbb R\times H^4$ crossing a radial solution at $s=0$.
