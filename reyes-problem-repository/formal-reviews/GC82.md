## Canonical mathematical statement

**Model freeze.** Let $m>0,\alpha\ge0$, $u\in H^2(\mathbb R^2;\mathbb C)$ with $M(u)=\|u\|_2^2=m$, $E_{\alpha,1}(u)=\|(\Delta+1)u\|_2^2-\frac12\|u\|_4^4+\frac13\|u\|_6^6+\alpha\|K_1(u)\|_2^2$. Use the Bessel $H^2$ norm $\int(1+|\xi|^2)^2|\widehat u|^2\,d\xi$.

**Precise mathematical target / proven narrower result.** The claimed coercivity estimate holds, with constants independent of $\alpha\ge0$: $\boxed{E_{\alpha,1}(u)\ge\frac12\|u\|_{H^2}^2-\frac{67}{16}m}$. Indeed, for $s=|u|^2$, $-\frac12s^2+\frac13s^3\ge-\frac3{16}s$. Moreover $(1+t)^2\le2(1-t)^2+8$ for $t=|\xi|^2$, so $\|u\|_{H^2}^2\le2\|(\Delta+1)u\|_2^2+8m$. The curvature term is nonnegative. These identities answer the precise v1 yes/no question for all fixed masses.

**Original scope text (preserved for comparison):**

For $m>0$ and $\alpha\ge0$, define $I_\alpha(m)=\inf\{E_{\alpha,1}(u):u\in H^2(\mathbb R^2;\mathbb C),\ M(u)=m\}$ using K and W. Determine whether for every fixed $m>0$ and $\alpha>0$ there are $c_{m,\alpha}>0,C_{m,\alpha}<\infty$ such that $E_{\alpha,1}(u)\ge c_{m,\alpha}\|u\|_{H^2}^2-C_{m,\alpha}$ for all admissible $u$.

## Notes / remaining modeling decisions

This proves fixed-mass coercivity, not coercivity uniformly over unrestricted mass and not strict binding. It does not prove compactness modulo translations.
