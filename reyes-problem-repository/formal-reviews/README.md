# Reyes Problem Repository: 300 formal-review pages

**Scope:** Every GC01–GC300 entry now has a separate review page with its source mathematical target, model and quantifier notes, resolution criteria, related prior-art leads, subproblem milestones, and explicit status recommendations. **These are first-pass research reviews, not 300 individually verified novel open problems or 300 completed proofs.**

[Main roadmap](../ROADMAP_300.md) · [Verified exact-scope Lean results](../VERIFIED_LEAN_RESULTS.md) · [Original formal statements](../FORMAL_PROBLEMS.md) · [Scoped GC65–GC300 source dossiers](../scoped/README.md) · [Status registry](../STATUS.md)

## Read the evidence labels carefully

- **Source target:** the existing question or scope-v1 target is reproduced as mathematics; a screen cannot silently revise it.
- **Literature leads:** published references verified as subject-related starting points, **not** a per-problem independent search or novelty certificate.
- **Refined draft:** model, nonvacuity, prior-art or topology decisions remain before formal promotion.
- **Withdraw/merge recommendation:** the exact finite or classical question may already be answered and deserves a proof record rather than an open-problem badge.
- **Registry remains authoritative** and is not modified by this review layer.
