# GC104: Floquet eigenvalue shift of periodic fourth-order operator

**Version:** concrete mathematical target v1 (2026-10-30). **Status:** mathematically proposed, not prior-art-certified or proved. Shared definitions: [COMMON_MODELS](COMMON_MODELS.md). Historical candidate: [GC104](../problems/03-spectral-scattering/GC104.md).

## Exact question

On \(L^2(\mathbb T^2)\) and for \(\alpha\in[-1/10,1/10]\), set \(H_\alpha(\theta)=((\nabla+i\theta)^2+1)^2+2+\alpha\cos x_1\) for \(\theta\in[-1/2,1/2]^2\), domain \(H^4\). With ordered eigenvalues \(\lambda_j(\alpha,\theta)\), determine the best uniform-in-\(\theta\) modulus of \(|\lambda_j(\alpha,\theta)-\lambda_j(0,\theta)|\) for each fixed j as \(\alpha\to0\).

## Proof or counterexample acceptance

A \(|\alpha|\) perturbation estimate is elementary; if sharpness is asserted, exhibit a branch with nonzero first-order correction. This is a valid spectral benchmark, not automatically an unsolved problem.
