# GC105: Golden-rule spectral coupling at a threshold

**Version:** concrete mathematical target v1 (2026-10-30). **Status:** mathematically proposed, not prior-art-certified or proved. Shared definitions: [COMMON_MODELS](COMMON_MODELS.md). Historical candidate: [GC105](../problems/03-spectral-scattering/GC105.md).

## Exact question

Let \(H_0=(\Delta+1)^2\) and \(\lambda=1\). For \(g\in C_c^\infty(\mathbb R^2;\mathbb C)\), define \(\Gamma(g)=\lim_{\eta\downarrow0}\operatorname{Im}\langle g,(H_0-\lambda-i\eta)^{-1}g\rangle\), whenever finite. Characterize precisely those g with \(\Gamma(g)>0\) using the Fourier restrictions to the dispersion shells \((|\xi|^2-1)^2=1\), and derive an explicit positive example.

## Proof or counterexample acceptance

This defines a concrete Fermi-golden-rule coefficient. A nonlinear damping consequence would be a separate theorem requiring a specified nonlinear bound state and modulation expansion.
