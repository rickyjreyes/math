# GC107: Monotonicity and spectral flow of defect eigenvalues

**Version:** concrete mathematical target v1 (2026-10-30). **Status:** mathematically proposed, not prior-art-certified or proved. Shared definitions: [COMMON_MODELS](COMMON_MODELS.md). Historical candidate: [GC107](../problems/03-spectral-scattering/GC107.md).

## Exact question

On \(L^2(\mathbb R^2)\), define \(H_t=(\Delta+1)^2-t e^{-|x|^2}\), \(t\in[0,10]\). For \(j\ge1\), let \(\lambda_j(t)\) be the jth negative eigenvalue counting multiplicity, where defined. Determine all t for which each \(\lambda_j(t)<0\) exists, and whether the ordered branches are strictly decreasing away from threshold crossings.

## Proof or counterexample acceptance

Min–max monotonicity is a standard starting theorem; crossing values and multiplicities are the more substantive classification. State exactly which j exists.
