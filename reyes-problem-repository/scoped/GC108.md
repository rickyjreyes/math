# GC108: Nonlinear localized states in periodic spectral gaps

**Version:** concrete mathematical target v1 (2026-10-30). **Status:** mathematically proposed, not prior-art-certified or proved. Shared definitions: [COMMON_MODELS](COMMON_MODELS.md). Historical candidate: [GC108](../problems/03-spectral-scattering/GC108.md).

## Exact question

Let \(H_{per}=(\Delta+1)^2+\cos x_1+\cos x_2\) on \(L^2(\mathbb R^2)\), domain \(H^4\). Determine whether its spectrum has a bounded open gap \((a,b)\) and, for any such gap, whether there exists \(\omega\in(a,b)\) and \(0\ne\phi\in H^4\) solving \((H_{per}-\omega)\phi-|\phi|^2\phi+|\phi|^4\phi=0\).

## Proof or counterexample acceptance

First prove the claimed linear gap exists; if it does not, that is the negative outcome for this frozen potential. If it does, require an exact L² localized nonlinear profile.
