# GC115: Anisotropic splitting of a dispersion-minimum shell

**Version:** concrete mathematical target v1 (2026-10-30). **Status:** mathematically proposed, not prior-art-certified or proved. Shared definitions: [COMMON_MODELS](COMMON_MODELS.md). Historical candidate: [GC115](../problems/03-spectral-scattering/GC115.md).

## Exact question

For \(0\le\varepsilon\le1\) let \(p_\varepsilon(k)=(|k|^2-1)^2+\varepsilon(k_1^4+k_2^4)\) on \(\mathbb R^2\). Determine the full global minimizer set \(\mathcal M_\varepsilon=\{k:p_\varepsilon(k)=\inf_{q\in\mathbb R^2}p_\varepsilon(q)\}\), its cardinality/topology for epsilon=0 versus epsilon>0, and the exact minimizing radius.

## Proof or counterexample acceptance

This is an explicitly solvable algebraic benchmark; distinguish a minimizing circle at epsilon=0 from the split discrete minima when epsilon>0.
