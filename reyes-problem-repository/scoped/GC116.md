# GC116: Aharonov–Bohm defect scattering

**Version:** concrete mathematical target v1 (2026-10-30). **Status:** mathematically proposed, not prior-art-certified or proved. Shared definitions: [COMMON_MODELS](COMMON_MODELS.md). Historical candidate: [GC116](../problems/03-spectral-scattering/GC116.md).

## Exact question

Let \(P_\alpha\) be the Friedrichs realization of \((-i\nabla-\alpha(-x_2,x_1)/|x|^2)^2\) on \(L^2(\mathbb R^2)\), initially defined on \(C_c^\infty(\mathbb R^2\setminus\{0\})\), \(\alpha\in[0,1]\). Define the fourth-order operator \(H_\alpha=(P_\alpha-1)^2\) via functional calculus. Determine which alpha give a scattering operator unitarily equivalent to that of \(H_0\), and compute any nontrivial angular-channel phase shifts.

## Proof or counterexample acceptance

Functional calculus fixes the fourth-order self-adjoint extension. Any scattering construction must state the comparison dynamics and avoid treating an undefined point-vortex boundary condition as harmless.
