# GC117: Galerkin spectral pollution for a periodic fourth-order operator

**Version:** concrete mathematical target v1 (2026-10-30). **Status:** mathematically proposed, not prior-art-certified or proved. Shared definitions: [COMMON_MODELS](COMMON_MODELS.md). Historical candidate: [GC117](../problems/03-spectral-scattering/GC117.md).

## Exact question

On \(L^2(\mathbb R)\) let \(H=(\partial_x^2+1)^2+\cos x\) with domain \(H^4\). Let \(X_N=\operatorname{span}\{h_0,\ldots,h_{N-1}\}\) be the first N real Hermite functions and \(P_N\) their L² projector. If the spectrum of H has a bounded open gap \(G\), decide whether there exist eigenvalues \(\lambda_N\in\sigma(P_NH|_{X_N})\cap G\) converging to a point \(\lambda\in G\setminus\sigma(H)\).

## Proof or counterexample acceptance

First verify existence of the chosen gap; if none exists the question has an explicit negative first branch. A reported spurious limit requires actual finite N Ritz eigenvalues and a proof it lies in the resolvent.
