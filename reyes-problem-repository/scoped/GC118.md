# GC118: Counting spatially concentrated bounded-domain eigenmodes

**Version:** concrete mathematical target v1 (2026-10-30). **Status:** mathematically proposed, not prior-art-certified or proved. Shared definitions: [COMMON_MODELS](COMMON_MODELS.md). Historical candidate: [GC118](../problems/03-spectral-scattering/GC118.md).

## Exact question

On \(\Omega=(0,\pi)^2\) let \(L=(-\Delta_D-1)^2\), with \(-\Delta_D\) the Dirichlet Laplacian and domain inherited through functional calculus. Enumerate the normalized eigenfunctions \(\phi_{mn}=2\pi^{-1}\sin(mx_1)\sin(nx_2)\), \(m,n\ge1\), eigenvalues \((m^2+n^2-1)^2\). Fix \(B=B_{1/4}((\pi/2,\pi/2))\) and count \(N_q(\Lambda)=\#\{(m,n):\lambda_{mn}\le\Lambda,\int_B|\phi_{mn}|^2\ge q\}\) for \(q=1/20\). Determine the sharp asymptotic of \(N_q(\Lambda)\) as \(\Lambda\to\infty\).

## Proof or counterexample acceptance

On a bounded domain the spectrum is discrete, so these are concentrated eigenfunctions rather than scattering resonances. The problem now has an exact spectral basis, localization test and counting convention.
