# GC119: Embedded nonlinear stationary modes

**Version:** concrete mathematical target v1 (2026-10-30). **Status:** mathematically proposed, not prior-art-certified or proved. Shared definitions: [COMMON_MODELS](COMMON_MODELS.md). Historical candidate: [GC119](../problems/03-spectral-scattering/GC119.md).

## Exact question

For \(V(x)=-e^{-|x|^2}\) define \(H_V=(\Delta+1)^2+V\). Determine whether there exists \(\omega>0\) and nonzero \(\phi\in H^4(\mathbb R^2;\mathbb C)\) solving \((H_V-\omega)\phi-|\phi|^2\phi+|\phi|^4\phi=0\), with \(\omega\in\sigma_{\rm ess}(H_V)=[0,\infty)\). If such a state exists, determine whether solutions persist for every sufficiently small amplitude perturbation \(\varepsilon e^{-2|x|^2}\) of V.
