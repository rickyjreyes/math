# GC120: Best quartic interpolation constant

**Scoped mathematical target v1, 2026-10-30.** Reference: [W model](COMMON_MODELS.md); original candidate: [GC120](../problems/04-variational-solitons/GC120.md). Not yet certified novel or unresolved.

## Exact statement / classification set

For nonzero \(u\in H^2(\mathbb R^2;\mathbb C)\), set \(Q(u)=\frac{\|u\|_4^4}{\|u\|_2^2+\|(\Delta+1)u\|_2^2+\|u\|_6^6}\) and \(C_*=\sup_{u\ne0}Q(u)\). Determine whether \(0<C_*<\infty\), compute its sharp value or variational characterization, and decide whether an optimizer exists modulo translations and phases.

## Decisive resolution criterion

The exact inhomogeneous inequality, all powers and the space are fixed. Unbounded maximizing sequences or nonattainment count as negative conclusions; an unrelated Gagliardo–Nirenberg inequality does not give the sharp constant automatically.

## Review gate

Check admissibility, operator domain, possible vacuity, the simplest counterexamples, and matching prior art. A named theorem is accepted only under exactly the displayed assumptions; do not promote registry status automatically.
