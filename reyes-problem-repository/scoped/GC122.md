# GC122: Attainment at the first negative-energy mass

**Scoped mathematical target v1, 2026-10-30.** Reference: [W model](COMMON_MODELS.md); original candidate: [GC122](../problems/04-variational-solitons/GC122.md). Not yet certified novel or unresolved.

## Exact statement / classification set

Write \(I(m)=\inf\{E_W(u):u\in H^2(\mathbb R^2),\ M(u)=m\}\) and define \(m_c=\inf\{m>0:I(m)<0\}\), \(\inf\emptyset=\infty\). Determine whether \(m_c\in(0,\infty)\), and, if so, whether \(I(m_c)\) is attained by any nonzero \(H^2\) field.

## Decisive resolution criterion

The threshold is fixed independently of any attainment claim. Prove 0<mc<∞ before asserting critical-mass minimizers, or report endpoint failure as the outcome.

## Review gate

Check admissibility, operator domain, possible vacuity, the simplest counterexamples, and matching prior art. A named theorem is accepted only under exactly the displayed assumptions; do not promote registry status automatically.
