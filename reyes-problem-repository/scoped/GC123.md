# GC123: Quantitative minimizer-orbit coercivity

**Scoped mathematical target v1, 2026-10-30.** Reference: [W model](COMMON_MODELS.md); original candidate: [GC123](../problems/04-variational-solitons/GC123.md). Not yet certified novel or unresolved.

## Exact statement / classification set

Fix \(m>0\) with nonempty minimizer set \(\mathcal M_m\). For \(r>0\) define \(\delta_m(r)=\inf\{E_W(u)-I(m):M(u)=m,\ \operatorname{dist}_{H^2}(u,\mathcal M_m)\ge r\}\), with inf empty=∞. Determine for which m and r one has \(\delta_m(r)>0\), and whether \(\delta_m(r)\ge c_m r^2\) for sufficiently small r.

## Decisive resolution criterion

Exact constrained deficit and quotient distance are fixed. A separated minimizing sequence proves failure; a compactness/coercivity proof establishes positivity.

## Review gate

Check admissibility, operator domain, possible vacuity, the simplest counterexamples, and matching prior art. A named theorem is accepted only under exactly the displayed assumptions; do not promote registry status automatically.
