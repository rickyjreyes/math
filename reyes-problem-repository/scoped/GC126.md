# GC126: Fourier-shell profile decomposition

**Scoped mathematical target v1, 2026-10-30.** Reference: [W model](COMMON_MODELS.md); original candidate: [GC126](../problems/04-variational-solitons/GC126.md). Not yet certified novel or unresolved.

## Exact statement / classification set

Let \(u_n\in H^2(\mathbb R^2)\) obey \(\|u_n\|_2=1\), \(\sup_n\|u_n\|_{H^2}<\infty\), and \(\operatorname{supp}\widehat u_n\subset\{\xi:||\xi|-1|\le1/n\}\). Determine whether there exist translations \(x_n^j\), profiles \(\phi^j\in H^2\), and remainders \(r_n^J\) with \(u_n=\sum_{j=1}^J\phi^j(\cdot-x_n^j)+r_n^J\) and \(\lim_{J\to\infty}\limsup_n\|r_n^J\|_{L^4}=0\), with asymptotic mass decoupling.

## Decisive resolution criterion

Verify whether any nonzero fixed H² profile is compatible with shell thickness shrinking to zero; if none, the correct 'decomposition' may be vanishing plus frequency-dependent profiles rather than the proposed sum.

## Review gate

Check admissibility, operator domain, possible vacuity, the simplest counterexamples, and matching prior art. A named theorem is accepted only under exactly the displayed assumptions; do not promote registry status automatically.
