# GC128: Mass-dependent strict binding region

**Scoped mathematical target v1, 2026-10-30.** Reference: [W model](COMMON_MODELS.md); original candidate: [GC128](../problems/04-variational-solitons/GC128.md). Not yet certified novel or unresolved.

## Exact statement / classification set

For \(m>0\) set \(I(m)=\inf_{M(u)=m}E_W(u)\). Define \(B=\{m>0:\forall\mu\in(0,m),\ I(m)<I(\mu)+I(m-\mu)\}\) and \(\Delta_m(\mu)=I(\mu)+I(m-\mu)-I(m)\). Determine the set B and its boundary, and whether \(\inf_{0<\mu<m}\Delta_m(\mu)/\min(\mu,m-\mu)>0\) for each m in B.

## Decisive resolution criterion

The binding condition and uniform-strength refinement are distinct. Explicit equalities or nearly splitting configurations test either claim; a named 'threshold' is not assumed to exist.

## Review gate

Check admissibility, operator domain, possible vacuity, the simplest counterexamples, and matching prior art. A named theorem is accepted only under exactly the displayed assumptions; do not promote registry status automatically.
