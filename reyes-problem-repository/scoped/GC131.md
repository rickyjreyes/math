# GC131: Morse index of excited constrained critical points

**Scoped mathematical target v1, 2026-10-30.** Reference: [W model](COMMON_MODELS.md); original candidate: [GC131](../problems/04-variational-solitons/GC131.md). Not yet certified novel or unresolved.

## Exact statement / classification set

For each real \(\phi\in H^4\setminus\{0\}\) satisfying \(F_\omega(\phi)=0\) and changing sign, define \(n^-(\phi)=\dim\mathbf1_{(-\infty,0)}(L_+)L^2\). Determine whether \(n^-(\phi)\ge2\) for every sign-changing stationary state, and classify those with equality.

## Decisive resolution criterion

The phrase 'excited' is frozen as sign-changing, and Morse index refers to the real Hessian L+. If there are no sign-changing states, a separate existence question remains.
