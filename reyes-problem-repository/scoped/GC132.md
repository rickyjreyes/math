# GC132: Constrained mountain-pass critical levels

**Scoped mathematical target v1, 2026-10-30.** Reference: [W model](COMMON_MODELS.md); original candidate: [GC132](../problems/04-variational-solitons/GC132.md). Not yet certified novel or unresolved.

## Exact statement / classification set

For \(m>0\) let \(S_m=\{u\in H^2(\mathbb R^2):M(u)=m\}\). Let \(\mathcal L_m\) be the collection of distinct \(G\)-orbits of strict local minimizers of \(E_W|_{S_m}\). For any two distinct \([u_0],[u_1]\in\mathcal L_m\), define \(c(u_0,u_1)=\inf_{\gamma\in C([0,1],S_m),\gamma(0)=u_0,\gamma(1)=u_1}\max_{t\in[0,1]}E_W(\gamma(t))\). Determine whether some m has \(|\mathcal L_m|\ge2\) and c is attained by a nonminimal constrained critical point.

## Decisive resolution criterion

The two minima must first exist; if not, the mountain-pass formulation has no endpoints. Palais–Smale modulo translations and endpoint orbit conventions require explicit proof.

Check admissibility, operator domain, possible vacuity, the simplest counterexamples, and matching prior art. A named theorem is accepted only under exactly the displayed assumptions; do not promote registry status automatically.
