# GC134: Large-mass geometry of minimizers

**Scoped mathematical target v1, 2026-10-30.** Reference: [W model](COMMON_MODELS.md); original candidate: [GC134](../problems/04-variational-solitons/GC134.md). Not yet certified novel or unresolved.

## Exact statement / classification set

For each \(m>0\) with nonempty \(\mathcal M_m\) minimizing E_W, define \(A(m)=\sup_{u\in\mathcal M_m}\|u\|_{L^\infty}\) and \(R(m)=\inf_{u\in\mathcal M_m}r_{9/10}(u)\). Determine the exact asymptotic behavior of A(m) and R(m) along \(m\to\infty\) for which minimizers exist.

## Decisive resolution criterion

Prove large-m existence and matching upper/lower growth bounds; distinguish a statement true for a chosen branch from one uniform over all minimizers.

## Review gate

Check admissibility, operator domain, possible vacuity, the simplest counterexamples, and matching prior art. A named theorem is accepted only under exactly the displayed assumptions; do not promote registry status automatically.
