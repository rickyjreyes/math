# GC136: Local minima under fourfold pinning

**Scoped mathematical target v1, 2026-10-30.** Reference: [W model](COMMON_MODELS.md); original candidate: [GC136](../problems/04-variational-solitons/GC136.md). Not yet certified novel or unresolved.

## Exact statement / classification set

On \(\mathbb T^2\), consider \(E_a(u)=\int(|(\Delta+1)u|^2-\tfrac12|u|^4+\tfrac13|u|^6+a(\cos4x_1+\cos4x_2)|u|^2)dx\), \(M(u)=1\), \(a\in[-1,1]\). Classify local minimizer G-orbits with G now restricted to constant phase and discrete period-\(\pi/2\) translations, and determine values of a where the number of symmetry-inequivalent strict local minima changes.

## Decisive resolution criterion

State the correct discrete symmetry group: the potential destroys continuous translations. Use constrained Hessians and bifurcation criteria, not visual stripe counts.
