# GC143: Instantaneous spreading for fourth-order Schrödinger flow

**Mathematical target v1 (2026-10-30)**. Original: [GC143](../problems/05-higher-derivative-fields/GC143.md). Not literature-certified open; no Lean resolution asserted.

## Exact problem

For nonzero \(u_0\in C_c^\infty(\mathbb R^2;\mathbb C)\), set \(u(t)=e^{-it(\Delta+1)^2}u_0\). Decide whether \(u(t,\cdot)\) can have compact spatial support for any \(t\ne0\). Independently classify the sharp weighted off-support estimates \(\|\mathbf1_{|x|>R}u(t)\|_2\) for fixed t and large R.

## Resolution test

Use the exact Fourier multiplier and a Paley–Wiener or explicit propagator argument. Distinguish literal finite support speed from rapid dispersive tails.

Check operator/action conventions, domains and quantifiers, possible classical solutions or immediate counterexamples, and closest literature. Preserve the original candidate as a historical sketch.
