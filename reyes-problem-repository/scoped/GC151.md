# GC151: Positive nonlocal parent with finite-wave-number preference

**Mathematical target v1 (2026-10-30)**. Original: [GC151](../problems/05-higher-derivative-fields/GC151.md). Not literature-certified open; no Lean resolution asserted.

## Exact problem

On \(L^2(\mathbb R^2)\) define the nonlocal Fourier multiplier with symbol \(p_\alpha(k)=1+|k|^2+\alpha e^{-|k|^2}\), \(\alpha>0\). Show \(p_\alpha(k)>0\) for all k and classify alpha for which the unique minimizing **radius** is nonzero; derive it explicitly. Determine whether this positive symbol can be represented as local second-order energy plus convolution with a positive-definite Gaussian kernel.

## Resolution test

The positive-parent example and exact dispersion are fixed. A minimizing ring is not a uniquely oriented mode and says nothing on its own about nonlinear pattern stability.
