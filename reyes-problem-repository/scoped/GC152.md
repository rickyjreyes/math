# GC152: Real branches versus Hamiltonian ghosts

**Mathematical target v1 (2026-10-30)**. Original: [GC152](../problems/05-higher-derivative-fields/GC152.md). Not literature-certified open; no Lean resolution asserted.

## Exact problem

For \(A,B\in\mathbb R\), consider \(P(\omega)=\omega^4-A\omega^2+B\). Characterize exactly the coefficient set where P has four distinct real nonzero roots. Separately for the single-coordinate Lagrangian \(L=\tfrac12\ddot q^2-\tfrac A2\dot q^2+\tfrac B2q^2\), determine whether the canonical Ostrogradsky Hamiltonian is bounded below on its unconstrained phase space.

## Resolution test

Do not equate real frequency branches with positive energy. The task explicitly separates an algebraic root condition from the ghost/energy obstruction.
