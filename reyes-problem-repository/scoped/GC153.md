# GC153: Patterned vacua of a periodic higher-gradient energy

**Mathematical target v1 (2026-10-30)**. Original: [GC153](../problems/05-higher-derivative-fields/GC153.md). Not literature-certified open; no Lean resolution asserted.

## Exact problem

For real \(u\in H^2(\mathbb T^2)\), define \(E(u)=\int_{\mathbb T^2}(|(\Delta+1)u|^2+(u^2-1)^2)dx\). Determine whether every global minimizer is spatially constant; if not, construct a nonconstant minimizing state or prove a strict trial-energy comparison against every constant and establish attainment.

## Resolution test

The nonnegative functional and domain are fixed. A finite Fourier trial state only disproves homogeneous optimality if its energy beats the minimum over all constants; global characterization is additional.
