# GC156: Constraint-preserving discrete evolution

**Mathematical target v1 (2026-10-30)**. Original: [GC156](../problems/05-higher-derivative-fields/GC156.md). Not literature-certified open; no Lean resolution asserted.

## Exact problem

On \(\mathbb R^4\) with canonical coordinates \((q_1,p_1,q_2,p_2)\) define \(H=\tfrac12(q_1^2+p_1^2)\) and constraints \(q_2=p_2=0\). Let \(\Phi_h\) be the implicit midpoint map on \((q_1,p_1)\), leaving \((q_2,p_2)\) exactly zero. Prove for every h>0 and integer n that \(\Phi_h^n\) preserves constraints and energy, and derive global error \(\sup_{0\le nh\le T}\|\Phi_h^n(z_0)-z(nh)\|\le C_T h^2\) for constrained initial data.

## Resolution test

The constrained Hamiltonian and algorithm are fixed, making this a formal-numerical verification benchmark. Extending to a genuine nontrivial Dirac constraint system is separate work.
