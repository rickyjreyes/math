# GC159: Minimal sensors for a two-parameter wave potential

**Concrete target v1, 2026-10-30.** The exact mathematical model, data and decision criterion are below. Original: [GC159](../problems/06-inverse-observation-control/GC159.md). Research/novelty status not yet certified.

## Frozen question

On \(\mathbb T^2\) solve \(u_{tt}+[(\Delta+1)^2+\theta_1\cos x_1+\theta_2\cos x_2]u=0\), with \(u(0,x)=e^{\cos x_1+\cos x_2}\), \(u_t(0)=0\), and \(\theta\in[-1/10,1/10]^2\). For each finite sensor set \(S=\{x_j\}_{j=1}^N\subset\mathbb T^2\), define \(F_S(\theta)=(u_\theta(1,x_j))_j\). Determine the smallest N for which some S yields rank\(DF_S(0)=2\), and exhibit such a configuration.

## Acceptance and falsification

The PDE, parameter family, time, initial data and local identifiability rank are fixed. Establish differentiability and compute sensitivity solutions rather than assuming sensors are informative.

## Review

Audit all measurements, source-model correspondences, identifiability symmetries, noise/precision, quantifiers, and previous theorems. Do not claim verification from a theorem about another forward model.
