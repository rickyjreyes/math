# GC161: Sensor dropout robustness of a fixed sensitivity matrix

**Concrete target v1, 2026-10-30.** The exact mathematical model, data and decision criterion are below. Original: [GC161](../problems/06-inverse-observation-control/GC161.md). Research/novelty status not yet certified.

## Frozen question

Set \(A=\begin{pmatrix}1&0\\0&1\\1&1\\1&-1\end{pmatrix}\). For any retained row set \(S\subset\{1,2,3,4\}\), define \(\sigma_S=\sigma_{\min}(A_S)\), with \(\sigma_S=0\) if rank\(A_S<2\). Determine \(\kappa_r=\min_{|S|=4-r}\sigma_S\) for each \(r\in\{0,1,2,3,4\}\), and the maximum number of failed channels that preserves local 2-parameter identifiability for **every** failure pattern.

## Acceptance and falsification

The worst-case deletion quantifier, matrix and singular-value convention are fixed. This may be elementary linear algebra and serves as a rigorous sensor-failure benchmark.
