# GC167: Exact two-component phase retrieval and minimal four-intensity family

**Mathematical resolution note v2 (2026-10-30).** Historical candidate: [GC167](../problems/06-inverse-observation-control/GC167.md). **The frozen finite-dimensional statement is solved by elementary algebra; this is not a newly unsolved research problem.** The value is as a certified-theorem or Lean-formalization candidate.

## Frozen map

For \(z=(z_1,z_2)\in\mathbb C^2\) define
\[
F(z)=\left(|z_1|^2,\ |z_2|^2,\ |z_1+z_2|^2,\ |z_1+iz_2|^2\right)
=(m_1,m_2,m_3,m_4).
\]
**Claim:** \(F(z)=F(w)\) if and only if \(w=e^{i\theta}z\) for some real theta. No subset of three of the specified four measurements has this property for **all** vectors, including zero components. Hence the minimal cardinality within this four-measurement menu is exactly four.

## Direct proof

Set \(c=z_1\overline{z_2}\). The four intensities determine the entire Gram matrix \(zz^*\), since
\[
|z_1|^2=m_1,\quad |z_2|^2=m_2,\quad
\operatorname{Re}c=(m_3-m_1-m_2)/2,\quad
\operatorname{Im}c=(m_4-m_1-m_2)/2.
\]
Equality of rank-one Gram matrices implies equality of the spanning complex lines and their norms, hence equality up to one global unit phase (including z=w=0). This proves sufficiency.

Each omission admits an explicit **non-global-phase-equivalent collision**, written as a pair \((z,w)\):
- Omit m₄: \(((1,i),(1,-i))\).
- Omit m₃: \(((1,1),(1,-1))\).
- Omit m₂: \(((1,0),(1,-1+i))\).
- Omit m₁: \(((0,1),(-1-i,1))\).

Check the three retained intensities in each case by direct complex arithmetic. Any two-measurement subset is contained in a failing three-measurement subset, proving minimality.

## Literature and remaining work

The four-measurement minimum in \(\mathbb C^2\) is a well-studied phase-retrieval bound; see M. Fickus, D. Mixon, A. Nelson and Y. Wang, *Phase Retrieval from Very Few Measurements* (2014), https://arxiv.org/abs/1307.7176. The optical polarization identity is classical, including W. D. Montgomery, *Phase retrieval and the polarization identity*, Optics Letters 2 (1978), 120–121, https://doi.org/10.1364/OL.2.000120. A Lean 4 encoding of the exact proof, or noise stability for these four measurements, would be **new work in this repository**, but not a new mathematics conjecture without further literature analysis.
