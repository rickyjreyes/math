# GC167: Two-component intensity-interferometric phase retrieval

**Concrete target v1, 2026-10-30.** The exact mathematical model, data and decision criterion are below. Original: [GC167](../problems/06-inverse-observation-control/GC167.md). Research/novelty status not yet certified.

## Frozen question

For \(z=(z_1,z_2)\in\mathbb C^2\), define \(F(z)=(|z_1|^2,|z_2|^2,|z_1+z_2|^2,|z_1+i z_2|^2)\in\mathbb R^4\). Decide whether \(F(z)=F(w)\) implies \(w=e^{i\theta}z\) for some \(\theta\in\mathbb R\) for all z,w, including zeros. Determine the smallest number of these four measurements sufficient for that property.

## Acceptance and falsification

This is a fully specified finite-dimensional phase-retrieval theorem. An explicit collision disproves a smaller-mask claim.

## Review

Audit all measurements, source-model correspondences, identifiability symmetries, noise/precision, quantifiers, and previous theorems. Do not claim verification from a theorem about another forward model.
