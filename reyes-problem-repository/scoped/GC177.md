# GC177: Bloch sideband stability of planar stripes

**Candidate mathematical specification v1 (2026-10-30).** Original: [GC177](../problems/07-pattern-formation/GC177.md). Precise mathematical questions are not certified open or solved.

## Explicit model and quantified target

For real \(u(t,x)\) on \(\mathbb R^2\), fix \(u_t=2u-(1+\Delta)^2u-u^3\). Let \(\mathscr S\) be the set of nonconstant real \(2\pi\)-periodic \(H^4_{per}(0,2\pi)\) profiles \(\phi(x_1)\) satisfying \(2\phi-(1+\partial_1^2)^2\phi-\phi^3=0\). For each \(\phi\in\mathscr S\) and \(\theta\in[-1/2,1/2]^2\), let \(L_\phi(\theta)=2-[1+(\nabla+i\theta)^2]^2-3\phi^2\) on \(H^4(\mathbb T^2)\). Determine which profiles satisfy \(\sup_{\theta\ne0}\sup\operatorname{Re}\sigma(L_\phi(\theta))\le0\) and identify the small-θ expansion.

## Proof-or-counterexample test

The Bloch problem is on the infinite periodic medium, not falsely equated with discrete Fourier modes of a single finite torus. Establish a stripe solution first and count neutral translation modes.
