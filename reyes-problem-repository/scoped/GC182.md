# GC182: Defect-density decay in a specified stochastic initial ensemble

**Candidate mathematical specification v1 (2026-10-30).** Original: [GC182](../problems/07-pattern-formation/GC182.md). Precise mathematical questions are not certified open or solved.

## Explicit model and quantified target

On \(\mathbb T_L^2\), let \(A_t=\Delta A+A-|A|^2A\) with \(L=2\pi N\). Choose random smooth initial fields \(A(0,x)=\sum_{0<|k|\le3}g_k e^{ik\cdot x/N}\) where independent circular complex Gaussians have variance \((1+|k|^2)^{-3}\). Let \(D_L(t)\) be the number of isolated zeros with nonzero real Jacobian divided by L² (defined as 0 if the zero set is not isolated). Determine whether a power \(\alpha>0\) exists for which \(\lim_{t\to\infty}\lim_{N\to\infty}t^\alpha\mathbb E D_L(t)\in(0,\infty)\).

## Proof-or-counterexample test

The sampling law, counting rule and limit order are fixed, although the finite Fourier indexing should be interpreted on the reciprocal lattice consistently. A different exponent or noncommuting limits refute universality.
