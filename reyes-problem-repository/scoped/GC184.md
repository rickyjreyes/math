# GC184: Spectrally striped localized stationary patches

**Candidate mathematical specification v1 (2026-10-30).** Original: [GC184](../problems/07-pattern-formation/GC184.md). Precise mathematical questions are not certified open or solved.

## Explicit model and quantified target

For \(\mu=2\), seek a nonzero \(u\in H^4(\mathbb R^2;\mathbb R)\) solving \(\mu u-(1+\Delta)^2u-u^3=0\). Define stripe-rich localization by \(\int_{3/4\le|\xi|\le5/4}|\widehat u(\xi)|^2d\xi\ge0.8\|u\|_2^2\) and \(r_{9/10}(u)<\infty\). Determine whether any such state exists and, if so, the sign of the spectral bound of \(L_u=\mu-(1+\Delta)^2-3u^2\) on L².

## Proof-or-counterexample test

These two explicit tests replace pictorial 'stripe patch'. Localization radius is always finite for nonzero L² u, so the substantive requirement is existence plus concentration; use a nontrivial bound on r if needed.
