# GC188: Finite-dimensional noisy stripe escape

**Candidate mathematical specification v1 (2026-10-30).** Original: [GC188](../problems/07-pattern-formation/GC188.md). Precise mathematical questions are not certified open or solved.

## Explicit model and quantified target

Let \(P_N\) project onto Fourier \(|k|\le N\) on \(\mathbb T^2\), N=3, and let \(E_N\) be the projected Swift–Hohenberg gradient energy \(E(u)=\int[\tfrac12|(1+\Delta)u|^2-\tfrac\mu2u^2+\tfrac14u^4]dx\), μ=2. On the finite-dimensional real Fourier coefficient space solve \(dX_t=-\nabla E_N(X_t)dt+\sqrt{2\varepsilon}dW_t\). For a fixed strict local minimum a of E_N and escape region \(D=B_{1/10}(a)\), determine \(\lim_{\varepsilon\to0}\varepsilon\log\mathbb E_a\tau_{\partial D}\).

## Proof-or-counterexample test

The noise, finite-dimensional state, drift and stopping set make the question well-defined; first establish an actual strict minimum a, otherwise the conditional exit problem has no base state.
