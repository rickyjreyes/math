# GC190: Stable aperiodic equilibrium of scalar Swift–Hohenberg flow

**Candidate mathematical specification v1 (2026-10-30).** Original: [GC190](../problems/07-pattern-formation/GC190.md). Precise mathematical questions are not certified open or solved.

## Explicit model and quantified target

For \(u_t=2u-(1+\Delta)^2u-u^3\) on \(\mathbb R^2\), seek a bounded real \(u_*\in C_b^4\) satisfying the stationary equation and Bohr almost periodicity, but **not** periodic with any full-rank lattice. Define stability using the uniformly-local norm \(\|v\|_{H^2_{uloc}}=\sup_{a\in\mathbb R^2}\|v\|_{H^2(B_1(a))}\). Determine whether there exists such u* whose translation orbit is Lyapunov stable in this norm.

## Proof-or-counterexample test

The non-L² whole-space state and uniformly-local topology are explicit; prove global flow in this topology before using orbital stability. Quasiperiodic trial superpositions are not automatically equilibria.

Confirm nonempty model class, trace and limiting conventions, dimensional consistency, closest existing theorems and the exact counterexample alternative. Preserve historical draft and defer novelty certification.
