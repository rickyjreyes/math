# GC191: Sharp algebraic relaxation at a degenerate equilibrium

**Candidate mathematical specification v1 (2026-10-30).** Original: [GC191](../problems/07-pattern-formation/GC191.md). Precise mathematical questions are not certified open or solved.

## Explicit model and quantified target

On \(\mathbb T^2\) solve \(u_t=u-(1+\Delta)^2u-u^3\) with real \(u_0\in H^2\) sufficiently small. Since the linearized operator at 0 has kernel Fourier modes \(|k|=1\), determine whether every such solution with no unstable spectral component obeys \(\|u(t)\|_{L^2}\le C(u_0)(1+t)^{-1/2}\), and exhibit an initial state with matching lower asymptotic.

## Proof-or-counterexample test

An actual center-manifold or normal-form argument must control quartic mode interactions; linear semigroup decay alone is insufficient.
