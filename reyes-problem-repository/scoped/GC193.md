# GC193: Persistent pattern switching after a temporary forcing

**Candidate mathematical specification v1 (2026-10-30).** Original: [GC193](../problems/07-pattern-formation/GC193.md). Precise mathematical questions are not certified open or solved.

## Explicit model and quantified target

On \(\mathbb T^2\), solve \(u_t=2u-(1+\Delta)^2u-u^3+f(t,x)\), \(f(t,x)=A\mathbf1_{[0,T]}(t)\cos2x_1\), \(A,T>0\). Start at a specified spectrally stable unforced stationary stripe \(\phi\in H^4\). Determine whether there exist A,T and a second stable stationary orbit \(G\psi\ne G\phi\) with \(u(t)\to G\psi\) in H² as t→∞ after the forcing is removed.

## Proof-or-counterexample test

Prove two distinct stable equilibria and the basin transition; a temporary Fourier response is not permanent switching. If no such two-orbit setup exists, report that obstruction.

## Independent verification gate

Confirm nonempty model class, trace and limiting conventions, dimensional consistency, closest existing theorems and the exact counterexample alternative. Preserve historical draft and defer novelty certification.
