# GC215: Decidability of a polynomial dissipative PDE basin

**Explicit decision problem v1 (2026-10-30).** Original: [GC215](../problems/09-computability-complexity/GC215.md). No unverified complexity hardness or novelty is asserted.

## Model, encoding and quantified question

Input: rational \(a_1,a_3\) and a finite rational trigonometric polynomial \(u_0\) on \(\mathbb T=\mathbb R/2\pi\mathbb Z\). Let \(u_t=u_{xx}-u^5+a_3u^3+a_1u\), \(u(0)=u_0\), with global real parabolic solution. Decide whether there exists a Turing algorithm that halts on every encoded input and outputs YES exactly when \(\|u(t)\|_{L^2}\to0\) as t→∞.

## Acceptance / disproof condition

The equation, rational input encoding, limit predicate and all-input quantifier are frozen. Prove uniform computability or reduce a known undecidable language; finite-time numerical convergence is not a decision procedure.

## Scope check

Any complexity-class result must use the exact input representation, resource and promise model stated above. Verify established complexity and computability results before marking open.
