# GC216: Binary-time prediction of a reversible radius-one rule

**Explicit decision problem v1 (2026-10-30).** Original: [GC216](../problems/09-computability-complexity/GC216.md). No unverified complexity hardness or novelty is asserted.

## Model, encoding and quantified question

For each n≥2 let states \((a_i,b_i)\in\mathbb F_2^2\) on a periodic ring \(i\in\mathbb Z/n\mathbb Z\). Define \(R(a,b)_i=(b_i,a_i\oplus b_{i-1})\). Input all 2n initial bits, binary-encoded T≥0, and target output pair at i=0 after T steps. Classify the uniform bit complexity (and parallel circuit depth) of this function in n+\lceil\log_2(T+1)\rceil.

## Acceptance / disproof condition

The reversible map and input encoding are exact. First exhibit its inverse, then compare repeated simulation to fast linear matrix exponentiation; do not assert universality or hardness without reduction.

## Scope check

Any complexity-class result must use the exact input representation, resource and promise model stated above. Verify established complexity and computability results before marking open.
