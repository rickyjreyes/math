# GC217: Optimal bounded-tape Rule-110 simulation overhead

**Explicit decision problem v1 (2026-10-30).** Original: [GC217](../problems/09-computability-complexity/GC217.md). No unverified complexity hardness or novelty is asserted.

## Model, encoding and quantified question

Fix elementary cellular automaton Rule 110 with synchronous updates on bi-infinite \(\{0,1\}^\mathbb Z\) and finite-support encodings above a fixed periodic background. Consider uniform computable encoders E that map a binary-encoded Turing machine M, input x, and tape bound S to a Rule-110 initial state of length polynomial in \(|M|+|x|+S\), and decoders that reproduce M's bounded-tape computation after at most \(p(T,S,|M|)\) CA steps whenever M halts in T steps. Determine the smallest possible polynomial degree of p among valid uniform simulations.

## Acceptance / disproof condition

The optimization is over explicitly defined encoders and decoders; specify periodic background and resource measure in each proof. Known Rule-110 universality is not itself an optimal overhead theorem.

## Scope check

Any complexity-class result must use the exact input representation, resource and promise model stated above. Verify established complexity and computability results before marking open.
