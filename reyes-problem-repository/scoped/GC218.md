# GC218: Communication complexity of half-ring cellular prediction

**Explicit decision problem v1 (2026-10-30).** Original: [GC218](../problems/09-computability-complexity/GC218.md). No unverified complexity hardness or novelty is asserted.

## Model, encoding and quantified question

For n even, apply the binary linear rule \(x_i(t+1)=x_i(t)\oplus x_{i-1}(t)\) on \(\mathbb F_2^n\) with periodic indices. Alice knows x_0,…,x_{n/2−1}, Bob knows the rest and must output the entire right-half vector \((x_{n/2}(T),…,x_{n−1}(T))\) after T steps, T given to both. Determine the minimum number of bits in a deterministic one-way Alice-to-Bob protocol for each (n,T).

## Acceptance / disproof condition

The answer equals the rank over F2 of the cross-block of the Tth update matrix; prove this equivalence and compute or bound it. A one-cell parity protocol is not enough for this vector-output task.

Any complexity-class result must use the exact input representation, resource and promise model stated above. Verify established complexity and computability results before marking open.
