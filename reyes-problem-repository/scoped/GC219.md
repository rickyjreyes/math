# GC219: Uniform parallel powering of a reversible cellular update

**Explicit decision problem v1 (2026-10-30).** Original: [GC219](../problems/09-computability-complexity/GC219.md). No unverified complexity hardness or novelty is asserted.

## Model, encoding and quantified question

For the reversible ring rule R in GC216, input n and binary T, output the entire state \(R^T(x)\). Construct a logspace-uniform Boolean circuit family with polynomial size and depth bounded by \(O(\log T\cdot\log^2n)\), or prove that this stated bound fails in the selected circuit basis.

## Acceptance / disproof condition

The update is F2-linear and exact matrix powering provides a concrete upper bound; state bit-length and fan-in conventions. It is not a claim that every reversible CA admits such a circuit.

## Scope check

Any complexity-class result must use the exact input representation, resource and promise model stated above. Verify established complexity and computability results before marking open.
