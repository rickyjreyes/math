# GC221: Precision needed to predict the doubling map

**Explicit decision problem v1 (2026-10-30).** Original: [GC221](../problems/09-computability-complexity/GC221.md). No unverified complexity hardness or novelty is asserted.

## Model, encoding and quantified question

Let \(f(x)=2x\bmod1\) on [0,1), and let \(b_T(x)=\lfloor2f^T(x)\rfloor\in\{0,1\}\). An algorithm receives only the first p binary digits of x and must output bT(x) for every non-dyadic x consistent with that prefix. Determine the minimal p as a function of T, and formulate an appropriate gap promise around dyadic boundaries under which a finite p gives a uniform guarantee.

## Acceptance / disproof condition

Without a margin promise no finite precision distinguishes points arbitrarily close to a digit boundary; the required T+1st bit is an exact lower bound on unrestricted prefix data.

Any complexity-class result must use the exact input representation, resource and promise model stated above. Verify established complexity and computability results before marking open.
