## Working mathematical model

Finite binary reversible wave-cell benchmark on the ring `ℤ/nℤ`: `x_j(t+1)=x_j(t−1)⊕x_{j−1}(t)⊕x_{j+1}(t)` with input of two initial slices. Time T is unary encoded unless explicitly changed; a pair-state update is reversible.

This is a **benchmark choice for a first rigorous attempt**. It does not silently change the original research question, imply an existing solution or assert that the benchmark is the only admissible physical model.

## Candidate mathematical question

Quantify how the input bits required for a certified prediction grow when trajectories approach a hyperbolic unstable set.

**Quantifiers and domain discipline:** Specify output bit/predicate, uniformity, input size n, horizon T and cost (gate count, depth, bits or communication). Prove reductions only for the fixed rule/encoding; no automatic physical P versus NP claim.

**Observable to define explicitly:** time, sequential work, parallel depth, memory or communication lower bound. Provide the exact norm, parameter ranges, and dependence of any claimed constant, bound, rate or threshold on all inputs.

## First decisive result

Prove a sharp dependence on Lyapunov rate and horizon.

**Valid negative outcomes:** An exact faster algorithm, simulation protocol or adversarial lower-bound witness for the frozen decision problem.

State at least one precisely checkable theorem or counterexample on the benchmark. If the desired reference state, operator or measurement does not exist, that nonvacuity obstruction must be resolved **before** treating any conditional conclusion as substantive.
