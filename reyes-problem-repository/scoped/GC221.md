# GC221: Precision needed to predict the doubling map

**Explicit decision problem v1 (2026-10-30).** Original: [GC221](../problems/09-computability-complexity/GC221.md). No unverified complexity hardness or novelty is asserted.

## Model, encoding and quantified question

Let \(f(x)=2x\bmod1\) on \([0,1)\), and \(b_T(x)=\lfloor2f^T(x)\rfloor\in\{0,1\}\). An **exact-prefix oracle** supplies the first p binary digits of a non-dyadic x. Determine the minimum p(T) sufficient to output \(b_T(x)\) for every x with the supplied prefix. **Separately**, for an approximate-real oracle returning rational \(\widetilde x\) with \(|x-\widetilde x|\le2^{-p}\), impose the margin promise \(\operatorname{dist}(f^T(x),\{0,1/2,1\})\ge\gamma>0\), and derive a sufficient p(T,\gamma).

## Acceptance / disproof condition

For an exact-prefix oracle, p=T+1 exactly and no margin promise is needed: the (T+1)st digit determines \(b_T\). An approximate-value oracle has a different information model, and without a margin finite absolute-error approximations cannot always distinguish inputs across a decision boundary.
