# GC222: Complexity of validated polynomial wave truncation

**Explicit decision problem v1 (2026-10-30).** Original: [GC222](../problems/09-computability-complexity/GC222.md). No unverified complexity hardness or novelty is asserted.

## Model, encoding and quantified question

For n≥1 on \(\mathbb R^n\), consider \(\dot x=-Ax-x^{\odot3}\), where A is an input positive-definite rational symmetric matrix with \(\|A\|_2\le n\), and x(0) rational with \(\|x(0)\|_2\le1\). Given rational T>0 and 0<ε<1, construct a certified interval algorithm outputting an ε-enclosure of x(T); determine whether its bit cost is polynomial in n, bit-size(A,x0), T and \(\log(1/\varepsilon)\).

## Acceptance / disproof condition

The dissipativity yields a bounded domain; establish explicit derivative/conditioning estimates and verify all rounding bounds rather than calling ordinary integration certified.

## Scope check

Any complexity-class result must use the exact input representation, resource and promise model stated above. Verify established complexity and computability results before marking open.
