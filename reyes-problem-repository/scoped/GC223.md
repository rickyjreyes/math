# GC223: Arithmetic cost of a diagonal periodic wave resolvent

**Explicit decision problem v1 (2026-10-30).** Original: [GC223](../problems/09-computability-complexity/GC223.md). No unverified complexity hardness or novelty is asserted.

## Model, encoding and quantified question

On the finite 2D integer grid \(\Lambda_N=\{k\in\mathbb Z^2:|k_j|\le N\}\), define diagonal \(A_N(k)=(|k|^2-1)^2+i\eta\), \(\eta\in\mathbb Q\cap(0,1]\). Given rational \(\eta,\varepsilon>0\), output all \((2N+1)^2\) entries of \(A_N^{-1}\) within complex absolute error ε. Determine optimal arithmetic operation count and a bit-complexity bound using rational division or verified intervals.

## Acceptance / disproof condition

The output size gives a concrete Ω(N²) lower bound; precision and conditioning η→0 must be included in bit cost.

Any complexity-class result must use the exact input representation, resource and promise model stated above. Verify established complexity and computability results before marking open.
