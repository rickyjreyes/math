# GC225: Reversible workspace for an irreversible local rule

**Explicit decision problem v1 (2026-10-30).** Original: [GC225](../problems/09-computability-complexity/GC225.md). No unverified complexity hardness or novelty is asserted.

## Model, encoding and quantified question

Fix periodic Rule 110 on n cells and T unary steps. An admissible reversible circuit over NOT, CNOT and Toffoli receives n input bits, produces all n bits of the T-step state, and preserves the original input in a separate register; ancillas begin zero and must be restored zero, with circuit size at most (n+T)^3. Determine the least additional workspace A(n,T) beyond n input bits and n output bits permitting such circuits.

## Acceptance / disproof condition

Specify whether uniform circuit generation is required; prove upper bounds by reversible checkpointing and lower bounds in the same gate/time model. The reversible simulation must not overwrite its preserved input.

## Scope check

Any complexity-class result must use the exact input representation, resource and promise model stated above. Verify established complexity and computability results before marking open.
