# GC226: Polynomial invariants of a finite-field cellular map

**Explicit decision problem v1 (2026-10-30).** Original: [GC226](../problems/09-computability-complexity/GC226.md). No unverified complexity hardness or novelty is asserted.

## Model, encoding and quantified question

Let p=2, n≥1, and \(R:\mathbb F_2^n\to\mathbb F_2^n\) be the periodic nearest-neighbor update \(R(x)_i=x_i\oplus x_{i-1}\). Input a sparse multivariate polynomial \(f\in\mathbb F_2[X_1,…,X_n]\) encoded by monomial/exponent lists. Decide whether \(f(R(x))=f(x)\) for every \(x\in\mathbb F_2^n\); classify complexity in n and input bit length.

## Acceptance / disproof condition

Finite-field functional identities are modulo \(X_i^2-X_i\) after substitution. Give an exact algorithm and a hardness proof, if any, using the specified sparse encoding.

## Scope check

Any complexity-class result must use the exact input representation, resource and promise model stated above. Verify established complexity and computability results before marking open.
