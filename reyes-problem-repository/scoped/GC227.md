# GC227: Finite-time certification of entry into a convex gradient basin

**Explicit decision problem v1 (2026-10-30).** Original: [GC227](../problems/09-computability-complexity/GC227.md). No unverified complexity hardness or novelty is asserted.

## Model, encoding and quantified question

Input a rational symmetric A with \(I\preceq A\preceq10I\) and rational \(x_0\in\mathbb Q^n\). For \(x'=-Ax-x^{\odot3}\), define the invariant neighborhood \(B_\delta=\{\|x\|_2\le\delta\}\) for rational 0<δ<1. Produce an algorithm returning a rational \(T_\delta\) and a checkable certificate that \(x(t)\in B_\delta\) for all t≥Tδ; optimize dependence on \(\log(1/\delta)\).

## Acceptance / disproof condition

Strict convexity and dissipative decay make this promised case tractable. Do not generalize termination to arbitrary dissipative PDEs without a separate undecidability analysis.

## Scope check

Any complexity-class result must use the exact input representation, resource and promise model stated above. Verify established complexity and computability results before marking open.
