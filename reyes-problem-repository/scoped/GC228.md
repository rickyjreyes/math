# GC228: Light-cone versus algebraic circuit depth

**Explicit decision problem v1 (2026-10-30).** Original: [GC228](../problems/09-computability-complexity/GC228.md). No unverified complexity hardness or novelty is asserted.

## Model, encoding and quantified question

For rule \(R(x)_i=x_i\oplus x_{i-1}\) on a ring of length n, input x and binary T with 0≤T<n. Let \(S(n,T)=\{j: \binom{T}{j}\equiv1\pmod2,0\le j\le T\}\). Determine the smallest depth of bounded-fan-in XOR/AND/OR/NOT circuits computing \(R^T(x)_0\), in terms of \(|S(n,T)|\), and compare with a time-unrolled depth-T circuit.

## Acceptance / disproof condition

The information dependence is fixed by Lucas' theorem. Prove Ω(log|S|) from fan-in and an O(log|S|) balanced XOR construction; clarify that T itself is an encoded input if uniformity is claimed.

## Scope check

Any complexity-class result must use the exact input representation, resource and promise model stated above. Verify established complexity and computability results before marking open.
