# GC229: Fault-tolerant Rule-110 simulation under independent noise

**Explicit decision problem v1 (2026-10-30).** Original: [GC229](../problems/09-computability-complexity/GC229.md). No unverified complexity hardness or novelty is asserted.

## Model, encoding and quantified question

Fix elementary Rule 110 on the infinite binary lattice and independent bit-flip noise with probability p∈(0,1/2) on each cell after each synchronous update. Call a compiler E_n and decoder D_n polynomial-overhead if a finite-alphabet radius-r local encoded rule, with fixed r and alphabet independent of n,T, simulates T≤n^2 noiseless steps on any n-bit finite perturbation with final error probability ≤1/3 using at most poly(n,T) cells and steps. Determine the supremal p for which such a uniform fault-tolerant simulation exists.

## Acceptance / disproof condition

The physical randomness and overhead quantifiers are explicit. Prove an actual local correction scheme or a threshold impossibility; one-shot repetition without regeneration does not establish fault tolerance.

## Scope check

Any complexity-class result must use the exact input representation, resource and promise model stated above. Verify established complexity and computability results before marking open.
