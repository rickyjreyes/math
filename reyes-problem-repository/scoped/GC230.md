# GC230: Approximation of a polynomial basin-of-positivity radius

**Explicit decision problem v1 (2026-10-30).** Original: [GC230](../problems/09-computability-complexity/GC230.md). No unverified complexity hardness or novelty is asserted.

## Model, encoding and quantified question

Input a rational polynomial \(P:\mathbb R^n\to\mathbb R\) of total degree≤4 satisfying \(P(0)=0\), \(\nabla P(0)=0\), and \(D^2P(0)\succ0\). Define \(r_*(P)=\sup\{r\ge0: P(x)>0\ \forall x\text{ with }0<\|x\|_2\le r\}\in(0,\infty]\). Determine whether a Turing machine can approximate any **finite** r* within 2^-k from (P,k), and decide effectively whether r* is infinite.

## Acceptance / disproof condition

The strict local-minimum promise makes r*>0. Quantifier elimination over real closed fields is a starting point; account for algebraic endpoints and equality at the first violating radius.
