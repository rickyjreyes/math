# GC231: Certificate size for explicit binary cellular traces

**Explicit decision problem v1 (2026-10-30).** Original: [GC231](../problems/09-computability-complexity/GC231.md). No unverified complexity hardness or novelty is asserted.

## Model, encoding and quantified question

For the ring update \(R(x)_i=x_i\oplus x_{i-1}\), an **explicit step certificate** for T updates is a list \((x^{(0)},…,x^{(T)})\in(\mathbb F_2^n)^{T+1}\) checked by verifying every adjacent R relation. Determine tight worst-case bit length and verification time for this specific certificate representation and compare to a succinct repeated-squaring certificate.

## Acceptance / disproof condition

Under the explicit list contract the size is exactly n(T+1) bits, so do not misrepresent this obvious bound as a cryptographic lower bound for all possible proof systems.

## Scope check

Any complexity-class result must use the exact input representation, resource and promise model stated above. Verify established complexity and computability results before marking open.
