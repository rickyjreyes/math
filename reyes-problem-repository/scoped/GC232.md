# GC232: Bidirectional simulation of two fixed reversible rules

**Explicit decision problem v1 (2026-10-30).** Original: [GC232](../problems/09-computability-complexity/GC232.md). No unverified complexity hardness or novelty is asserted.

## Model, encoding and quantified question

On \((\mathbb F_2^2)^\mathbb Z\), let \(R(a,b)_i=(b_i,a_i\oplus b_{i-1})\) (GC216) and \(S(a,b)_i=(a_{i-1},b_{i-1})\) (shift). Define a simulation as a shift-commuting injective block encoder E of fixed finite radius and integers p,q≥1 with \(E\circ R^p=S^q\circ E\). Determine whether such an E exists in either direction, and if so the minimal temporal ratio p/q.

## Acceptance / disproof condition

The allowed codes, alphabet, locality and commutation diagram are exact. Polynomial-overhead nonlocal simulators would form a separate model.

## Scope check

Any complexity-class result must use the exact input representation, resource and promise model stated above. Verify established complexity and computability results before marking open.
