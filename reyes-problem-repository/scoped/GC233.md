# GC233: Promise gap of a rational graph Laplacian

**Explicit decision problem v1 (2026-10-30).** Original: [GC233](../problems/09-computability-complexity/GC233.md). No unverified complexity hardness or novelty is asserted.

## Model, encoding and quantified question

Input a finite connected simple graph G of n vertices, n≥2, encoded by adjacency matrix, and let L_G be its integer graph Laplacian. Given rational \(\delta=1/n^2\), under the promise that \(\lambda_2(L_G)\le\delta/2\) or \(\lambda_2(L_G)\ge2\delta\), decide which case holds. Classify deterministic bit complexity and whether a strongly polynomial spectral certificate exists.

## Acceptance / disproof condition

The promise is explicit; graph connectivity may make the first branch impossible for some n, which should be checked. Numeric eigenvalue approximations require certified rational error bounds.
