# GC234: Minimum thermodynamic work for imperfect bit reset

**Explicit decision problem v1 (2026-10-30).** Original: [GC234](../problems/09-computability-complexity/GC234.md). No unverified complexity hardness or novelty is asserted.

## Model, encoding and quantified question

Let an initially equiprobable classical bit X be reset to 0 using a thermal bath at fixed absolute temperature \(T_b>0\). The allowed protocols are quasistatic or finite-time Markov processes satisfying local detailed balance, ending with \(\mathbb P(X_{out}=1)\le p\) for 0≤p<1/2. Determine the infimum mean work \(W_*(p)\), counting externally driven energy changes, and whether \(W_*(p)\ge k_BT_b\ln2\,[1-h_2(p)]\) is sharp, where h2 is binary entropy in bits.

## Acceptance / disproof condition

Specify the endpoint Hamiltonians and free-energy convention when proving sharpness; a work–error bound is not determined by circuit depth alone.
