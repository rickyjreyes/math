# GC242: Implicit-function branch of a constant stationary wave

**Lean-oriented exact proposition v1 (2026-10-30).** Original: [GC242](../problems/10-lean-certified-analysis/GC242.md). Known analytic results and any existing Lean proofs must be distinguished from missing formalization.

## Exact mathematical theorem or verification target

On real \(H^2(\mathbb T^2)\) define \(F(\omega,u)=(\Delta+1)^2u-u^3+u^5-\omega u\) valued in H^{-2}. At \((\omega,u)=(1,1)\), F=0 and \(D_uF=(\Delta+1)^2+1\). Prove this is an isomorphism H²→H^{-2}; then construct neighborhoods U of ω=1 and V of u=1 and a unique C¹ map \(\phi:U\to V\) with \(F(\omega,\phi(\omega))=0\).

## Acceptance / caveat

The base state is an actual stationary solution and the inverse spectral multiplier is strictly positive. Lean must cover the function-space implicit-function step, not merely a scalar fifth-degree polynomial.
