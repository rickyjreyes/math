# GC250: Sound rational counterexample-witness format

**Lean-oriented exact proposition v1 (2026-10-30).** Original: [GC250](../problems/10-lean-certified-analysis/GC250.md). Known analytic results and any existing Lean proofs must be distinguished from missing formalization.

## Exact mathematical theorem or verification target

Define a certificate pair \((P,q)\) with \(P\in\mathbb Q[X_1,…,X_n]\), \(q\in\mathbb Q^n\), and exact rational evaluation \(\mathrm{eval}(P,q)<0\). Prove a trusted checker accepting such a pair establishes \(\neg(\forall x\in\mathbb R^n,P(x)\ge0)\), using the natural rational-to-real embedding.

## Acceptance / caveat

The schema and false theorem class are precise. A checker for arbitrary Lean propositions would require a separately specified and trusted syntax/elaboration boundary.

## Formal proof contract

A full resolution must identify Lean 4 declaration(s), exact theorem statement, Mathlib imports, successful exact-head CI, no sorry/admit or added unproved axioms, and independent theorem-to-mathematics correspondence. A file in this folder alone is **not** a Lean proof.
