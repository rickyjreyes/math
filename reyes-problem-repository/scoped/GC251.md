# GC251: Rational eigenvalue certificates for a 2×2 matrix

**Lean-oriented exact proposition v1 (2026-10-30).** Original: [GC251](../problems/10-lean-certified-analysis/GC251.md). Known analytic results and any existing Lean proofs must be distinguished from missing formalization.

## Exact mathematical theorem or verification target

Take \(A=\begin{pmatrix}2&1\\1&3\end{pmatrix}\) with eigenvalues \(\lambda_\pm=(5\pm\sqrt5)/2\). Define a rational interval checker accepting disjoint intervals \(I_-=[1.38,1.39]\), \(I_+=[3.61,3.62]\) only if a determinant-sign/trace certificate proves each interval contains exactly one eigenvalue. Formalize soundness for symmetric rational 2×2 matrices and verify A's certificates.

## Acceptance / caveat

The interval endpoints are rational, and exact determinant evaluations suffice. Numeric floating-point eigenvectors alone are not valid Lean certificates.
