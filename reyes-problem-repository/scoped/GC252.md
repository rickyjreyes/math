# GC252: LaSalle convergence to a critical set

**Lean-oriented exact proposition v1 (2026-10-30).** Original: [GC252](../problems/10-lean-certified-analysis/GC252.md). Known analytic results and any existing Lean proofs must be distinguished from missing formalization.

## Exact mathematical theorem or verification target

Let \(V:\mathbb R^n\to\mathbb R\) be C², bounded below and with compact sublevel sets. Let x(t) be a global solution of \(x'=-\nabla V(x)\) with initial state x0. Prove \(\operatorname{dist}(x(t),\{x:\nabla V(x)=0\})\to0\) as t→∞, provided the critical set within the initial sublevel is nonempty.

## Acceptance / caveat

Use \(dV/dt=-\|\nabla V\|^2\) and precompactness of the orbit. This is a classical convergence-to-set theorem, not necessarily convergence to one equilibrium.
