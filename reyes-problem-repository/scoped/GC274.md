# GC274: Sampling-resolution threshold between two wave dispersions

**Model-complete research candidate v1 (2026-10-30)**. Original: [GC274](../problems/11-physical-emergence-multiscale/GC274.md). Mathematical well-definedness and prior-art novelty are separate review gates.

## Exact microscopic/continuum target

Fix \(\omega_A=1\), \(\omega_B=1+\delta\), 0<δ<1/10, and signals \(y_A(t)=\cos(\omega_A t)\), \(y_B(t)=\cos(\omega_B t)\). Observe on a grid \(t_j=j\tau\), 0≤j≤N, with deterministic errors \(|e_j|\le\eta\). Determine the smallest N and largest τ-dependent noise margin permitting exact discrimination for all error sequences, and classify aliasing as τ varies.

## Decisive test and caveat

The decision criterion is \(\max_j|y_A(t_j)-y_B(t_j)|>2\eta\), with finite observation time Nτ. This is an exact baseline for more complicated effective-wave-model comparisons.

## Review conditions

Verify dimensional units, Fourier and interpolation conventions, existence of relevant solutions, quantifier/limit order and matched error estimate. A formal limiting expansion by itself is not a convergent approximation theorem.
