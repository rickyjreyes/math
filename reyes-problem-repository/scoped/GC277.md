# GC277: Worst-case phase and detector tolerance for an XOR interferometer

**Device-level mathematical candidate v1, 2026-10-30.** [Original GC277](../problems/12-photonic-wave-computing/GC277.md). The device model is idealized and **not** an experimentally validated optical implementation.

## Explicit physical abstraction and quantified mathematical target

Encode bits a,b∈{0,1} as phases φ_a=aπ+e_a, φ_b=bπ+e_b, with |e_a|,|e_b|≤ε and 0≤ε≤π/4. Set the normalized balanced-interferometer output I=(1−cos(φ_a−φ_b))/2 and detector Y=I+η with |η|≤δ. A bit is decoded as 1 iff Y>1/2. Determine the largest ε for each δ≥0 for which the decoded XOR is correct for **all** four inputs and all permitted errors.

## Proof or counterexample acceptance

Use the exact worst-case margins I_00,I_11≤sin²ε and I_01,I_10≥cos²ε. Robustness requires sin²ε+δ<1/2 (with boundary tie handled by the strict threshold). This is a theorem about a stated device model, not unspecified optical hardware.

## Scientific and formalization boundary

Prove all logical implications for the stated inputs, component transfer functions, limits and error models. Note any already elementary result rather than declaring a novel open conjecture. A mathematical truth table does not certify fabricated hardware; any Lean statement must match this model exactly.
