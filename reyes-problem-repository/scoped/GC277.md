# GC277: Robust two-input interferometric XOR

**Photonic mathematical specification v1 (2026-10-30).** Original: [GC277](../problems/12-photonic-wave-computing/GC277.md). Precise models do not automatically constitute physical implementation or a new open result.

## Exact device/logic model and quantified claim

Encode bits a,b∈{0,1} as optical phases πa,πb on equal-amplitude fields. Define detector signal S(a,b)=|e^{iπa}-e^{iπb}|²/4 and decoded bit 1 iff S≥1/2. Under phase errors |δ_a|,|δ_b|≤ε and additive detector error |η|≤ν, determine the exact set of (ε,ν) for which all four XOR truth-table outputs remain correct for every allowed error.

## Formal resolution and negative test

Compute exact maximum same-bit signal and minimum different-bit signal, including equality at threshold; the robustness statement must quantify worst-case errors, not merely average.

## Readiness gate

Audit detector thresholds, input/output encoding, amplification and nonlinear readout, worst-case or stochastic errors, units and robustness. Separate mathematical circuit semantics from hardware measurements and novelty.
