# GC278: NAND without a reference beam in passive optics

**Device-level mathematical candidate v1, 2026-10-30.** [Original GC278](../problems/12-photonic-wave-computing/GC278.md). The device model is idealized and **not** an experimentally validated optical implementation.

## Explicit physical abstraction and quantified mathematical target

Let a,b∈{0,1} be encoded as optical input amplitudes z=(a,b)∈C². Let U∈U(2) be an arbitrary passive lossless linear network and let output bit c=1 iff |(Uz)_1|²>τ for a threshold τ≥0. Determine whether **any** pair (U,τ) realizes c=NAND(a,b) for every input. Repeat if one additional always-on reference amplitude z₀=1 is admitted as a third input of U∈U(3).

## Proof or counterexample acceptance

With no reference, input 00 gives intensity zero and output 0 for every τ≥0, a decisive NAND obstruction. Any reference-enabled construction must count the powered reference and nonlinear threshold, not claim universality from strictly linear propagation alone.

## Scientific and formalization boundary

Prove all logical implications for the stated inputs, component transfer functions, limits and error models. Note any already elementary result rather than declaring a novel open conjecture. A mathematical truth table does not certify fabricated hardware; any Lean statement must match this model exactly.
