# GC278: Passive linear optics with terminal threshold readout

**Photonic mathematical specification v1 (2026-10-30).** Original: [GC278](../problems/12-photonic-wave-computing/GC278.md). Precise models do not automatically constitute physical implementation or a new open result.

## Exact device/logic model and quantified claim

Let x∈{0,1}^n be encoded as a complex amplitude vector z(x)∈{0,1}^n. An allowed circuit is one fixed unitary U∈U(m) with m−n vacuum inputs and outputs y_j=1[|(Uz)_j|²≥τ_j]; no intermediate measurements, feedforward, active amplification or nonlinear elements. Determine whether this class can realize the two-output half-adder map (a,b)↦(a XOR b,a AND b) exactly for all four inputs, and what minimum m suffices if possible.

## Formal resolution and negative test

The threshold readout is nonlinear, so a universal 'linear optics cannot compute AND' assertion is invalid without this model. Construct U and thresholds or give an exact impossibility proof.

## Readiness gate

Audit detector thresholds, input/output encoding, amplification and nonlinear readout, worst-case or stochastic errors, units and robustness. Separate mathematical circuit semantics from hardware measurements and novelty.
