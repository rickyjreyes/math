# GC278: No-reference NAND obstruction and reference-assisted construction

**Exact finite-model mathematical resolution v2 (2026-10-30).** Historical candidate: [GC278](../problems/12-photonic-wave-computing/GC278.md). This is idealized optical amplitude arithmetic, **not verified fabricated hardware**.

## Model and outcome

Encode a,b∈{0,1} as complex coherent amplitude inputs. A passive lossless network is unitary U. Decode the first output to 1 iff \(|(Uz)_1|^2>\tau\), with \(\tau\ge0\).

**Without a reference beam:** for z=(a,b)∈C² and any U∈U(2), input 00 gives z=0, first output amplitude 0 and bit 0. NAND(0,0)=1. Thus no such (U,τ) can compute NAND at all four inputs.

**With one always-on reference beam:** set z=(1,a,b)∈C³ and choose any U∈U(3) whose first row is \((2,-1,-1)/\sqrt6\). This unit vector can be completed to a unitary matrix by orthonormal extension. Then the first output is \((2-a-b)/\sqrt6\). Its four detected intensities are
\[
I_{00}=4/6,\qquad I_{01}=I_{10}=1/6,\qquad I_{11}=0.
\]
Choosing \(\tau=1/12\) gives exactly NAND: 1,1,1,0.

## Resource and novelty boundary

The construction **does not** compute NAND without a powered optical reference, threshold detector, or a nonlinear digital readout. The minimum reference power and noise margin could be separate optimization questions with fully specified physical resource accounting. This particular existence/obstruction pair is solved algebraically and does not constitute an original universal impossibility theorem.
