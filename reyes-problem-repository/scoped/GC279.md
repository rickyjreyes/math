# GC279: Optical logic cascading without regeneration

**Photonic mathematical specification v1 (2026-10-30).** Original: [GC279](../problems/12-photonic-wave-computing/GC279.md). Precise models do not automatically constitute physical implementation or a new open result.

## Exact device/logic model and quantified claim

Consider a scalar intensity logic stage x↦f(x) where intended bit states are intervals I0=[0,0.1], I1=[0.9,1], and noise η∈[-δ,δ] is added after each stage. Define f(x)=min(1,max(0,2x−1/2)). For all depths D≥1 and all noise sequences, decide whether the stage maps I_b into itself for b∈{0,1} and find the exact maximal δ≥0 preserving both invariant intervals.

## Formal resolution and negative test

Invariant intervals give a concrete indefinite-depth regeneration criterion; a passive purely linear optical channel does not implement this saturating f unless its nonlinear thresholding resource is declared.
