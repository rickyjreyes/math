# GC280: Finite-temperature diffusion limit of an optical phase memory

**Device-level mathematical candidate v1, 2026-10-30.** [Original GC280](../problems/12-photonic-wave-computing/GC280.md). The device model is idealized and **not** an experimentally validated optical implementation.

## Explicit physical abstraction and quantified mathematical target

For b∈{0,1}, let z_b(t)=e^{-γt}exp(i(bπ+√(2D)W_t)), where γ>0, D>0 and W_t is standard Brownian motion. A sensor samples Y_t=Re z_b(t)+N, N∼N(0,σ²) independent, σ>0, with equiprobable bits. Determine the optimal Bayesian error p_err(t) from the exact two conditional distributions and the supremum storage time T_p= sup{t≥0:p_err(t)≤p}, for fixed p∈(0,1/2).

## Proof or counterexample acceptance

Write the wrapped-normal/noisy-detector likelihoods or a convergent Fourier representation; any quoted storage time must follow from those distributions. Phase noise and amplitude loss are both included.

## Scientific and formalization boundary

Prove all logical implications for the stated inputs, component transfer functions, limits and error models. Note any already elementary result rather than declaring a novel open conjecture. A mathematical truth table does not certify fabricated hardware; any Lean statement must match this model exactly.
