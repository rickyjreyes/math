# GC281: Passive scattering implementation of reversible bit swap

**Photonic mathematical specification v1 (2026-10-30).** Original: [GC281](../problems/12-photonic-wave-computing/GC281.md). Precise models do not automatically constitute physical implementation or a new open result.

## Exact device/logic model and quantified claim

Use two optical input channels, encode (a,b)∈{0,1}² as coherent amplitudes (a,b), and allow one lossless 2×2 scattering matrix U with detectors decoding output intensity by threshold 1/2. Determine whether the reversible transformation (a,b)↦(b,a) is implementable for all four inputs and characterize the minimal number of nonzero off-diagonal couplings.

## Formal resolution and negative test

The swap matrix gives a constructive benchmark. It does not establish universal reversible computation or copying of arbitrary quantum states.

## Readiness gate

Audit detector thresholds, input/output encoding, amplification and nonlinear readout, worst-case or stochastic errors, units and robustness. Separate mathematical circuit semantics from hardware measurements and novelty.
