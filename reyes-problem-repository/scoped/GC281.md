# GC281: Single-photon four-rail realization of CNOT

**Device-level mathematical candidate v1, 2026-10-30.** [Original GC281](../problems/12-photonic-wave-computing/GC281.md). The device model is idealized and **not** an experimentally validated optical implementation.

## Explicit physical abstraction and quantified mathematical target

Encode the two-bit basis (00,01,10,11) as a single photon in one of four orthogonal rails e₀,e₁,e₂,e₃. Define the passive four-port permutation U by Ue₀=e₀, Ue₁=e₁, Ue₂=e₃, Ue₃=e₂. Prove U†U=I and that a perfect rail-resolving detector implements the Boolean CNOT truth table. If each rail has independent transmission efficiency η∈[0,1], determine the probability of a conclusive correct output for each input.

## Proof or counterexample acceptance

The optical implementation uses one-hot encoding and four modes for two logical bits; it does not establish scalable two-qubit quantum gates or nonlinear classical fanout. Loss is an explicit erasure outcome.

## Scientific and formalization boundary

Prove all logical implications for the stated inputs, component transfer functions, limits and error models. Note any already elementary result rather than declaring a novel open conjecture. A mathematical truth table does not certify fabricated hardware; any Lean statement must match this model exactly.
