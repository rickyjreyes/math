# GC282: Precision scaling of a regenerated interferometric ripple-carry adder

**Device-level mathematical candidate v1, 2026-10-30.** [Original GC282](../problems/12-photonic-wave-computing/GC282.md). The device model is idealized and **not** an experimentally validated optical implementation.

## Explicit physical abstraction and quantified mathematical target

For n≥1, construct a classical n-bit ripple-carry adder entirely from idealized optical XOR, AND and OR modules followed by threshold detection and fresh output re-encoding at each logical stage. Bits are encoded as phases 0/π. Each module's phase errors satisfy |e|≤ε and output detection noise |η|≤δ, and assume each primitive's ideal Boolean truth table is correct whenever ε,δ satisfy its declared margin. Determine a uniform sufficient phase/noise margin to guarantee the entire n-bit sum and carry for all 2^{2n} inputs; under independent per-gate errors ≤p, give an end-to-end failure bound in n.

## Proof or counterexample acceptance

Provide the complete gate-level full-adder recurrence s_i=a_i⊕b_i⊕c_i, c_{i+1}=(a_i∧b_i)∨(c_i∧(a_i⊕b_i)), counting gate use. With ideal regeneration, worst-case per-gate margins need not shrink with n; without it accumulated errors are a different problem.

## Scientific and formalization boundary

Prove all logical implications for the stated inputs, component transfer functions, limits and error models. Note any already elementary result rather than declaring a novel open conjecture. A mathematical truth table does not certify fabricated hardware; any Lean statement must match this model exactly.
