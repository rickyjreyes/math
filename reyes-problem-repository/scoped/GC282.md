# GC282: Optical phase precision for binary integer addition

**Photonic mathematical specification v1 (2026-10-30).** Original: [GC282](../problems/12-photonic-wave-computing/GC282.md). Precise models do not automatically constitute physical implementation or a new open result.

## Exact device/logic model and quantified claim

For n-bit nonnegative integers A,B<2^n, encode their sum phase as θ=2π(A+B)/2^{n+1} modulo 2π and measure θ with deterministic absolute angular error ≤ε (circular distance). Decoder rounds to the nearest phase grid point, outputting A+B. Determine the maximal ε guaranteeing exact output for every input, and the scaling of required detector levels with n.

## Formal resolution and negative test

This is a precise idealized phase-encoding architecture. It assumes a phase adder has already produced θ, which cannot be inferred from passive superposition alone.
