# GC283: Minimum Poisson optical power for N-way fanout

**Device-level mathematical candidate v1, 2026-10-30.** [Original GC283](../problems/12-photonic-wave-computing/GC283.md). The device model is idealized and **not** an experimentally validated optical implementation.

## Explicit physical abstraction and quantified mathematical target

A classical bit 1 is a coherent source emitting a Poisson number of photons with mean μ; bit 0 emits none. Split the field equally among N output rails, each with detection efficiency η∈(0,1] and ideal threshold-click detector without dark counts. All N outputs must click to reproduce bit 1 reliably. Determine the smallest μ for which P(all N outputs click)≥1−p, where N∈N and p∈(0,1/2), and give sharp asymptotics at fixed p as N→∞.

## Proof or counterexample acceptance

Independent Poisson thinning gives P=(1−exp(−ημ/N))^N. Derive μ_min=−(N/η)ln[1−(1−p)^{1/N}] and its N log N scale. This concerns classical copy by power splitting, not quantum-state cloning.
