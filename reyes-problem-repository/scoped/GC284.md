## Working mathematical model

Finite classical coherent-amplitude benchmark: `z_out=Uz_in+e`, unitary `U∈ℂ^{N×N}`, `N≥2`, `‖z_in‖₂≤1`, noise `‖e‖₂≤10⁻²`, and threshold readout `b_j=1{|z_out,j|²≥τ}`, `τ∈(0,1)`. Intensity detection is nonlinear; it is not passive coherent propagation.

This is a **benchmark choice for a first rigorous attempt**. It does not silently change the original research question, imply an existing solution or assert that the benchmark is the only admissible physical model.

## Candidate mathematical question

Determine the scaling of worst-case output error in a depth-D cascade of phase-coded optical arithmetic operations.

**Quantifiers and domain discipline:** Freeze source encoding, device size N, U, detector threshold, control/reset budget and error tolerance before quantifying over all valid input words and disturbances.

**Observable to define explicitly:** gate truth table, noise margin, power budget, resource scaling or calibrated output. Provide the exact norm, parameter ranges, and dependence of any claimed constant, bound, rate or threshold on all inputs.

## First decisive result

Prove an error propagation theorem with saturation or correction conditions.

**Valid negative outcomes:** A competing circuit, indistinguishable inputs at threshold, or a violated worst-case noise margin.

State at least one precisely checkable theorem or counterexample on the benchmark. If the desired reference state, operator or measurement does not exist, that nonvacuity obstruction must be resolved **before** treating any conditional conclusion as substantive.
