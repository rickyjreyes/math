# GC284: Phase-error propagation through a depth-D optical circuit

**Device-level mathematical candidate v1, 2026-10-30.** [Original GC284](../problems/12-photonic-wave-computing/GC284.md). The device model is idealized and **not** an experimentally validated optical implementation.

## Explicit physical abstraction and quantified mathematical target

For D≥1, let accumulated phase error e_D=Σ_{j=1}^D(δ_j+Z_j), where |δ_j|≤ε deterministically and independent Z_j∼N(0,σ²). For target optical output exp(iφ) and actual exp(i(φ+e_D)), determine a sharp deterministic bound when σ=0 and, for σ>0, a confidence bound on |exp(ie_D)−1| valid with probability at least 1−p.

## Proof or counterexample acceptance

The drift sum can be as large as Dε while Gaussian variance is Dσ². A valid certificate combines these with a Gaussian tail or exact wrapped-normal probability; no arbitrary-depth guarantee is asserted without correction.

## Scientific and formalization boundary

Prove all logical implications for the stated inputs, component transfer functions, limits and error models. Note any already elementary result rather than declaring a novel open conjecture. A mathematical truth table does not certify fabricated hardware; any Lean statement must match this model exactly.
