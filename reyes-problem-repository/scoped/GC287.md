# GC287: Single-mode versus multimode saturation in coupled resonators

**Device-level mathematical candidate v1, 2026-10-30.** [Original GC287](../problems/12-photonic-wave-computing/GC287.md). The device model is idealized and **not** an experimentally validated optical implementation.

## Explicit physical abstraction and quantified mathematical target

For two complex resonator amplitudes z₁,z₂, let ż₁=(g−γ−s|z₁|²)z₁+iκz₂ and ż₂=(g−γ−s|z₂|²)z₂+iκz₁, with g=2,γ=1,s=1 and κ∈[0,1/2]. Define a stable mode as a relative equilibrium z_j(t)=e^{iΩt}a_j whose U(1)-phase orbit is Lyapunov stable in C². Classify all nonzero relative equilibria, their frequencies and stable orbits for each κ, and whether more than one distinct stable mode orbit exists.

## Proof or counterexample acceptance

Because global optical phase is a symmetry, a unique complex fixed vector is not a meaningful claim. Linearize in a phase-reduced slice and test symmetry-breaking branches, not only in-phase amplitudes.

## Scientific and formalization boundary

Prove all logical implications for the stated inputs, component transfer functions, limits and error models. Note any already elementary result rather than declaring a novel open conjecture. A mathematical truth table does not certify fabricated hardware; any Lean statement must match this model exactly.
