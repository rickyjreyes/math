# GC288: Thermal feedback margin for an optical XOR gate

**Device-level mathematical candidate v1, 2026-10-30.** [Original GC288](../problems/12-photonic-wave-computing/GC288.md). The device model is idealized and **not** an experimentally validated optical implementation.

## Explicit physical abstraction and quantified mathematical target

Let target phase φ*∈{0,π}, phase residual e_n updated by e_{n+1}=(1−K)e_n+w_n, with feedback gain K∈R, initial e₀=0 and |w_n|≤w. Two independently controlled XOR inputs obey this loop, and their detector output is I=(1−cos(φ_a−φ_b))/2 with additive bounded error |η|≤δ and threshold 1/2. Find all K,w,δ such that the XOR truth table remains correct for every n and every disturbance sequence.

## Proof or counterexample acceptance

For 0<K<2, the invariant residual bound is w/(1−|1−K|); plug this into the interferometer's two-input phase-difference margin. At K outside the stable interval, test worst-case drift rather than asserting robustness.
