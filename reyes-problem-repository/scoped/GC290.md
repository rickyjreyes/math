# GC290: Output-code capacity of a photon-limited coherent network

**Device-level mathematical candidate v1, 2026-10-30.** [Original GC290](../problems/12-photonic-wave-computing/GC290.md). The device model is idealized and **not** an experimentally validated optical implementation.

## Explicit physical abstraction and quantified mathematical target

Let α₁,…,α_K∈C^M be coherent output amplitude vectors of a passive network, each obeying ||α_j||₂²≤P. A heterodyne sensor returns Y=α_j+Z, with independent circular complex Gaussian components of variance σ²>0. Define K*(M,P,σ,p) as the greatest K for which some such codebook has maximum-likelihood error probability ≤p<1/2 for every equiprobable codeword. Determine rigorous upper and lower bounds on K* and its asymptotic scaling with P/σ² at fixed M,p.

## Proof or counterexample acceptance

Specify Gaussian complex variance and decoder convention; use packing/volume and constructive codebooks, not just counting real-valued continuum amplitudes as infinitely many reliable bits.

## Scientific and formalization boundary

Prove all logical implications for the stated inputs, component transfer functions, limits and error models. Note any already elementary result rather than declaring a novel open conjecture. A mathematical truth table does not certify fabricated hardware; any Lean statement must match this model exactly.
