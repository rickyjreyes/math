# GC292: Identifiability of two overlapping resonant memory addresses

**Device-level mathematical candidate v1, 2026-10-30.** [Original GC292](../problems/12-photonic-wave-computing/GC292.md). The device model is idealized and **not** an experimentally validated optical implementation.

## Explicit physical abstraction and quantified mathematical target

Store a∈{0,1}² and read y=K_κ a+η, where K_κ=[[1,κ],[κ,1]], κ∈[0,1] is real cross-talk and ||η||_∞≤δ. Determine the largest δ for which a deterministic decoder recovers **every** two-bit word under all permitted errors; classify the degenerate κ=1 case and exhibit an optimal decoder for κ<1.

## Proof or counterexample acceptance

Exact worst-case distinguishability is half the minimum L∞ distance between distinct codewords Kκa. Note that raw coordinate thresholding need not be optimal; cross-talk inversion is allowed when κ<1.

## Scientific and formalization boundary

Prove all logical implications for the stated inputs, component transfer functions, limits and error models. Note any already elementary result rather than declaring a novel open conjecture. A mathematical truth table does not certify fabricated hardware; any Lean statement must match this model exactly.
