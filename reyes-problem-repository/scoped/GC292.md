# GC292: Identifiability of two coupled resonator memory cells

**Photonic mathematical specification v1 (2026-10-30).** Original: [GC292](../problems/12-photonic-wave-computing/GC292.md). Precise models do not automatically constitute physical implementation or a new open result.

## Exact device/logic model and quantified claim

For complex memory amplitudes z=(z1,z2) with \(\|z\|≤1\), measured output y=Az+η where \(A=\begin{pmatrix}1&\kappa\\\kappa&1\end{pmatrix}\), real κ∈[0,2], and \(\|\eta\|_2≤δ\). Classify κ for which z is uniquely identifiable at δ=0 and derive the sharp worst-case reconstruction error \(\|\hat z-z\|≤C(κ)δ\) for a linear inverse when invertible.

## Formal resolution and negative test

The singular values are |1±κ|; report failure at κ=1. For noisy data any minimax guarantee must include the state domain and noise convention.
