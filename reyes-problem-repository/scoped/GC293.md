# GC293: Nonlinear pulse-collision AND switching

**Device-level mathematical candidate v1, 2026-10-30.** [Original GC293](../problems/12-photonic-wave-computing/GC293.md). The device model is idealized and **not** an experimentally validated optical implementation.

## Explicit physical abstraction and quantified mathematical target

On R solve the focusing cubic nonlinear Schrödinger equation i u_t=−(1/2)u_xx−|u|²u with initial u_{a,b}(0,x)=A[a e^{−(x+2)²}e^{2ix}+b e^{−(x−2)²}e^{−2ix}], a,b∈{0,1}, A∈(0,2]. At time t=1 measure I_{a,b}(A)=∫_{−1}^1|u_{a,b}(1,x)|² dx and decode 1 iff I>τ, τ>0. Determine whether there exist A,τ satisfying I_11(A)>τ≥max(I_00,I_01,I_10), and quantify the strict detection margin.

## Proof or counterexample acceptance

All four bit patterns, the nonlinear waveguide PDE, collision geometry and output test are frozen. A verified solution must solve/bound the PDE, not treat mere pulse overlap as an AND truth table.

## Scientific and formalization boundary

Prove all logical implications for the stated inputs, component transfer functions, limits and error models. Note any already elementary result rather than declaring a novel open conjecture. A mathematical truth table does not certify fabricated hardware; any Lean statement must match this model exactly.
