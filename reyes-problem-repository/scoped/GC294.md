# GC294: Reliability of redundant phase bits under independent faults

**Device-level mathematical candidate v1, 2026-10-30.** [Original GC294](../problems/12-photonic-wave-computing/GC294.md). The device model is idealized and **not** an experimentally validated optical implementation.

## Explicit physical abstraction and quantified mathematical target

Encode one classical logical bit into r=2m+1 identical optical phase bits, each decoded with independent error probability p∈[0,1/2), and recover by majority vote. Let P_fail(r,p)=Σ_{j=m+1}^r binom(r,j)p^j(1−p)^{r−j}. Find the smallest odd r guaranteeing error ≤ε for each ε∈(0,1/2), prove an exponential Chernoff/Hoeffding bound, and for a circuit of N independent decoded logical operations derive an r(N,ε) sufficient for total error ≤ε.

## Proof or counterexample acceptance

A logarithmic redundancy overhead is valid under stated independence and refreshed encoding; correlated thermal drift, no regeneration or analog phase correlations are outside this theorem.

## Scientific and formalization boundary

Prove all logical implications for the stated inputs, component transfer functions, limits and error models. Note any already elementary result rather than declaring a novel open conjecture. A mathematical truth table does not certify fabricated hardware; any Lean statement must match this model exactly.
