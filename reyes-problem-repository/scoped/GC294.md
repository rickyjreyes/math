# GC294: Majority-vote fault tolerance for redundant optical bits

**Photonic mathematical specification v1 (2026-10-30).** Original: [GC294](../problems/12-photonic-wave-computing/GC294.md). Precise models do not automatically constitute physical implementation or a new open result.

## Exact device/logic model and quantified claim

Encode one logical bit in 2r+1 independent component channels, each flipped with probability p∈[0,1/2), and decode by majority. Prove exact logical error \(P_r(p)=\sum_{j=r+1}^{2r+1}\binom{2r+1}{j}p^j(1-p)^{2r+1-j}\), show it decays exponentially in r for each fixed p<1/2, and derive the r required for target error ε.

## Formal resolution and negative test

Independent errors are a substantive assumption; correlated optical phase drift can invalidate the claimed exponential suppression. Encoding and resource count are explicit.

## Readiness gate

Audit detector thresholds, input/output encoding, amplification and nonlinear readout, worst-case or stochastic errors, units and robustness. Separate mathematical circuit semantics from hardware measurements and novelty.
