# GC295: Boolean semantics-preserving compilation to idealized phase gates

**Device-level mathematical candidate v1, 2026-10-30.** [Original GC295](../problems/12-photonic-wave-computing/GC295.md). The device model is idealized and **not** an experimentally validated optical implementation.

## Explicit physical abstraction and quantified mathematical target

Define inductive Boolean expressions E ::= Input(i)|Xor(E,E)|And(E,E)|Or(E,E). Assign each bit b∈{0,1} physical phase φ(b)=πb, and gate intensities X(a,b)=(1−cos(φ(a)−φ(b)))/2, A(a,b)=sin²(φ(a)/2)sin²(φ(b)/2), O(a,b)=sin²(φ(a)/2)+sin²(φ(b)/2)−sin²(φ(a)/2)sin²(φ(b)/2). After ideal threshold at 1/2 and **fresh phase re-encoding**, prove by structural induction that device evaluation equals Boolean expression evaluation for every input assignment.

## Proof or counterexample acceptance

AND/OR intensity mappings are stipulated nonlinear/combining device primitives, not derived solely from passive interferometers. An end-to-end compilation correctness theorem requires stating and justifying those primitives separately for hardware.

## Scientific and formalization boundary

Prove all logical implications for the stated inputs, component transfer functions, limits and error models. Note any already elementary result rather than declaring a novel open conjecture. A mathematical truth table does not certify fabricated hardware; any Lean statement must match this model exactly.
