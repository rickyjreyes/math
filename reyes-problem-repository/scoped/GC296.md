# GC296: Sound phase-and-power interval certificates for an XOR circuit

**Device-level mathematical candidate v1, 2026-10-30.** [Original GC296](../problems/12-photonic-wave-computing/GC296.md). The device model is idealized and **not** an experimentally validated optical implementation.

## Explicit physical abstraction and quantified mathematical target

For bits a,b∈{0,1}, suppose a calibrated sensor certifies φ_a∈[πa−ε,πa+ε], φ_b∈[πb−ε,πb+ε], detector additive noise η∈[−δ,δ], with ε∈[0,π/4], δ≥0. Define the checker to accept iff sin²ε+δ<1/2. Prove acceptance implies each of the four possible physical detector outputs I=(1−cos(φ_a−φ_b))/2+η lies strictly on the correct side of threshold 1/2 for the XOR table.

## Proof or counterexample acceptance

The interval premise must be a measured, conservatively rounded guarantee; a finite rational checker must bound π, trigonometric evaluations and detector calibration by certified intervals, not untrusted floating-point approximations.

## Scientific and formalization boundary

Prove all logical implications for the stated inputs, component transfer functions, limits and error models. Note any already elementary result rather than declaring a novel open conjecture. A mathematical truth table does not certify fabricated hardware; any Lean statement must match this model exactly.
