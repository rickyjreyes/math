# GC298: Robust locking range of two optical phase oscillators

**Device-level mathematical candidate v1, 2026-10-30.** [Original GC298](../problems/12-photonic-wave-computing/GC298.md). The device model is idealized and **not** an experimentally validated optical implementation.

## Explicit physical abstraction and quantified mathematical target

Let phase difference θ obey θ'=Δω−2K sinθ+w(t), K>0, |w(t)|≤η, with constant detuning Δω∈R and absolutely measurable disturbance w. Determine necessary/sufficient conditions for an invariant attracting phase interval contained strictly in (−π/2,π/2), uniformly for every allowed disturbance. Find the optimal worst-case phase-error bound and show loss of this guarantee when |Δω|+η≥2K.

## Proof or counterexample acceptance

The Kuramoto-type model and disturbance quantifier are explicit; bounded adversarial drift is not stochastic phase diffusion. Avoid asserting global attraction on the entire circle, which also contains unstable equilibria.

## Scientific and formalization boundary

Prove all logical implications for the stated inputs, component transfer functions, limits and error models. Note any already elementary result rather than declaring a novel open conjecture. A mathematical truth table does not certify fabricated hardware; any Lean statement must match this model exactly.
