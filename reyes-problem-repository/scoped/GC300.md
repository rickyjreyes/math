# GC300: End-to-end certified optical half-adder truth table

**Device-level mathematical candidate v1, 2026-10-30.** [Original GC300](../problems/12-photonic-wave-computing/GC300.md). The device model is idealized and **not** an experimentally validated optical implementation.

## Explicit physical abstraction and quantified mathematical target

Encode input bits a,b as measured phase intervals φ_a∈[πa−ε,πa+ε], φ_b∈[πb−ε,πb+ε], ε∈[0,π/4]. Define sum intensity S=(1−cos(φ_a−φ_b))/2, carry intensity C=sin²(φ_a/2)sin²(φ_b/2), independent detector offsets |η_S|,|η_C|≤δ, and decode both with a strict >1/2 threshold. Determine explicit **sufficient and sharp where possible** inequalities on ε,δ ensuring the exact Boolean half-adder sum a⊕b and carry ab simultaneously for all four inputs and every allowed physical error. Provide a compositional certificate of phase encoding, primitive formulas, bound propagation and detector decisions.

## Proof or counterexample acceptance

Sufficient margins are sin²ε+δ<1/2 and cos⁴(ε/2)−δ>1/2 (plus the carry-zero bound sin²(ε/2)+δ<1/2, implied in this range). The carry product is an explicitly assumed nonlinear optical primitive, not established as a passive linear implementation.

## Scientific and formalization boundary

Prove all logical implications for the stated inputs, component transfer functions, limits and error models. Note any already elementary result rather than declaring a novel open conjecture. A mathematical truth table does not certify fabricated hardware; any Lean statement must match this model exactly.
