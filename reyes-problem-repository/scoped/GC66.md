# GC66: Internal-mode radiation damping

**Version:** scoped mathematical target v1 (2026-10-30). **Readiness:** precise candidate, not literature-certified open, not proven, and not claimed Lean-verified. Original draft: [GC66](../problems/01-wave-dynamics/GC66.md). Shared definitions: [COMMON_MODELS](COMMON_MODELS.md).

## Exact mathematical target

For each nonzero real \(\phi\in H^4(\mathbb R^2)\) satisfying \(F_\omega(\phi)=0\), define \(\mathcal A_\phi\) as in W. Call an internal mode an \(L^2\) eigenvector of \(\mathcal A_\phi\) at \(i\nu\), \(0<\nu<1\), isolated from the essential spectrum. Determine whether **there exist** such \((\omega,\phi,\nu)\) and an \(H^2\)-open perturbation class of solutions whose Riesz-mode projection amplitude tends to zero as \(t\to+\infty\).

## What answers it

First establish the existence of the state and isolated eigenmode. If none exists, record that negative answer rather than assuming one. If one exists, distinguish vanishing mode projection from full asymptotic stability and specify the spectral projection.
