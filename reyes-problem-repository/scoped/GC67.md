# GC67: Traveling-wave velocity set

**Version:** scoped mathematical target v1 (2026-10-30). **Readiness:** precise candidate, not literature-certified open, not proven, and not claimed Lean-verified. Original draft: [GC67](../problems/01-wave-dynamics/GC67.md). Shared definitions: [COMMON_MODELS](COMMON_MODELS.md).

## Exact mathematical target

For each \(c\ge0\), let \(S_c=\{(\omega,\psi):\omega\in\mathbb R,\ 0\ne\psi\in H^4(\mathbb R^2;\mathbb C),\ e^{|x|/10}\psi\in H^4,\ (\Delta+1)^2\psi-|\psi|^2\psi+|\psi|^4\psi-\omega\psi+ic\partial_{x_1}\psi=0\}\). Classify the set \(\mathcal V=\{c\ge0:S_c\ne\varnothing\}\). The corresponding solution is \(u(t,x)=e^{-i\omega t}\psi(x-ct e_1)\).

## What answers it

For each claimed allowed velocity construct a profile or give an existence theorem; for excluded intervals rule out every frequency omega and exponentially localized profile. Avoid importing Galilean invariance from the ordinary second-order NLS.
