# GC68: Two-wave asymptotic scattering

**Version:** scoped mathematical target v1 (2026-10-30). **Readiness:** precise candidate, not literature-certified open, not proven, and not claimed Lean-verified. Original draft: [GC68](../problems/01-wave-dynamics/GC68.md). Shared definitions: [COMMON_MODELS](COMMON_MODELS.md).

## Exact mathematical target

Using W, define \(\mathcal T\) to be the collection of nonzero traveling solutions from GC67 whose velocities differ. Determine whether there exist a global \(H^2\) solution \(u\) and \(v_\pm\in\mathcal T\) such that \(\|u(t)-v_+(t)-v_-(t)\|_{H^2}\to0\) as \(t\to+\infty\), and the analogous limit as \(t\to-\infty\) holds with a possibly different pair. Classify how the outgoing pair depends on incoming asymptotic profiles.

## What answers it

The existence of suitable traveling solutions is part of the problem, not a hidden hypothesis. A negative result can demonstrate that the specified global two-channel asymptotic relation is impossible.
