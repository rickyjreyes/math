# GC70: Nonradial solitary waves

**Version:** scoped mathematical target v1 (2026-10-30). **Readiness:** precise candidate, not literature-certified open, not proven, and not claimed Lean-verified. Original draft: [GC70](../problems/01-wave-dynamics/GC70.md). Shared definitions: [COMMON_MODELS](COMMON_MODELS.md).

## Exact mathematical target

Let \(\mathscr S_m=\{(\omega,\phi):F_\omega(\phi)=0,\ 0\ne\phi\in H^4(\mathbb R^2),\ \|\phi\|_2^2=m\}\). Determine the set of masses \(m>0\) for which \(\mathscr S_m\) contains a profile that is **not radial about any translated center**, even after constant phase rotation. A bifurcation is a \(C^1\) curve \(s\mapsto(m(s),\omega(s),\phi_s)\) in \(\mathbb R_+\times\mathbb R\times H^4\) crossing a radial solution at \(s=0\).

## What answers it

Prove existence of a genuinely nonradial solution or rule it out for an explicitly bounded mass range. Merely exhibiting translations of a radial profile is not symmetry breaking.
