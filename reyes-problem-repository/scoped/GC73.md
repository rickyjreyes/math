# GC73: Quasiperiodic localized wave torus

**Version:** scoped mathematical target v1 (2026-10-30). **Readiness:** precise candidate, not literature-certified open, not proven, and not claimed Lean-verified. Original draft: [GC73](../problems/01-wave-dynamics/GC73.md). Shared definitions: [COMMON_MODELS](COMMON_MODELS.md).

## Exact mathematical target

For W seek \(u(t,x)=e^{-i\omega t}U(t,\sqrt2t,x)\), where \(U\in C^2(\mathbb T^2;H^4(\mathbb R^2))\) is \(2\pi\)-periodic in both angles and \(\sup_{\theta}\|e^{|x|/10}U(\theta,x)\|_{H^4}<\infty\). Require that \(U\) is not constant in either angular coordinate and contains a nonzero Fourier coefficient with each independent angular index. Decide whether such \((\omega,U)\) exist.

## What answers it

A proof constructs an exact two-frequency solution satisfying the equation for all angles, not a finite numerical Fourier truncation. A no-go argument may exploit resonance with the continuous spectrum.
