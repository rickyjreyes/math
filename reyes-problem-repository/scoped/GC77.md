# GC77: Logarithmic nonlinear escape time

**Version:** scoped mathematical target v1 (2026-10-30). **Readiness:** precise candidate, not literature-certified open, not proven, and not claimed Lean-verified. Original draft: [GC77](../problems/01-wave-dynamics/GC77.md). Shared definitions: [COMMON_MODELS](COMMON_MODELS.md).

## Exact mathematical target

Let \(\phi\) be a real stationary W state with an unstable simple eigenpair \(\mathcal A_\phi v=\lambda v\), \(\lambda>0\). For \(0<\varepsilon<1\) let \(u_\varepsilon(0)=\phi+\varepsilon(v_1+iv_2)\) and define \(T_\delta(\varepsilon)=\inf\{t\ge0:\operatorname{dist}_{H^2}(e^{i\omega t}u_\varepsilon(t),G\phi)\ge\delta\}\), where \(\delta>0\) is fixed below the branch's local orbit radius. Determine if \(T_\delta(\varepsilon)/\log(1/\varepsilon)\to1/\lambda\).

## What answers it

First verify the spectral eigenpair and local existence through the exit interval; prove both upper and lower asymptotics. The quantification is conditional, with vacuity noted if no such profile exists.
