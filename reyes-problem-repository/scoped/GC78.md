# GC78: Unbounded high-Sobolev growth

**Version:** scoped mathematical target v1 (2026-10-30). **Readiness:** precise candidate, not literature-certified open, not proven, and not claimed Lean-verified. Original draft: [GC78](../problems/01-wave-dynamics/GC78.md). Shared definitions: [COMMON_MODELS](COMMON_MODELS.md).

## Exact mathematical target

For W define \(\mathcal H=\{u_0\in H^3(\mathbb R^2):\text{the maximal H3 solution exists for all }t\ge0\}\). Decide whether there exists \(u_0\in\mathcal H\) with \(\sup_{t\ge0}\|u(t)\|_{H^3}=\infty\), although \(M(u(t))=M(u_0)\) and \(E_W(u(t))=E_W(u_0)\).

## What answers it

An affirmative answer requires one global trajectory, not a sequence of different initial data. A negative answer must prove bounded H3 norm for every element of H, not only each finite time interval.
