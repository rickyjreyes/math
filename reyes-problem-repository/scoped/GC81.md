# GC81: Uniform orbital stability near a branch end

**Version:** scoped mathematical target v1 (2026-10-30). **Readiness:** precise candidate, not literature-certified open, not proven, and not claimed Lean-verified. Original draft: [GC81](../problems/01-wave-dynamics/GC81.md). Shared definitions: [COMMON_MODELS](COMMON_MODELS.md).

## Exact mathematical target

For real stationary profiles \(\phi_s\in H^4\) with \(F_{\omega(s)}(\phi_s)=0\) and \(s\in(0,1]\), suppose \(s\mapsto(\omega(s),\phi_s)\) is continuous in \(\mathbb R\times H^4\), has an \(H^4\) limit at \(s\downarrow0\), and each orbit \(G\phi_s\) is orbitally stable in \(H^2\). Determine whether one can choose a common \(\delta(\eta)>0\) valid for every \(s\in(0,1]\) in the epsilon–delta definition of orbital stability, or construct a branch where no uniform delta exists.

## What answers it

An answer must quantify over all nearby initial data and all forward times; pointwise stability of each member does not automatically imply uniform branch stability.
