# GC91: Half-plane edge modes

**Version:** concrete mathematical target v1 (2026-10-30). **Status:** mathematically proposed, not prior-art-certified or proved. Shared definitions: [COMMON_MODELS](COMMON_MODELS.md). Historical candidate: [GC91](../problems/02-confinement-curvature/GC91.md).

## Exact question

Let \(\Omega=\mathbb R\times(0,\infty)\) and \(L=(\Delta+1)^2\) be the Friedrichs operator generated by \(\|(\Delta+1)u\|_2^2\) on \(H_0^2(\Omega)\). Let \(\mathcal E\) be the set of \(\lambda\in\mathbb R\) for which a nonzero generalized eigenfunction \(u(x,y)=e^{i\xi x}f(y)\), \(\xi\in\mathbb R\), \(f\in H^2(0,\infty)\cap L^2\), satisfies \(Lf=\lambda f\) and clamped conditions \(f(0)=f'(0)=0\). Determine \(\mathcal E\).

## Proof or counterexample acceptance

The problem is a precise edge-band classification, not an assertion that an edge state exists. Distinguish guided (L² in y) from whole-space L² modes.
