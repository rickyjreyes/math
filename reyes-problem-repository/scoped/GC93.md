# GC93: Minimal radius with energy-curvature budgets

**Version:** concrete mathematical target v1 (2026-10-30). **Status:** mathematically proposed, not prior-art-certified or proved. Shared definitions: [COMMON_MODELS](COMMON_MODELS.md). Historical candidate: [GC93](../problems/02-confinement-curvature/GC93.md).

## Exact question

For \(B,D>0\), let \(\mathcal A(B,D)=\{u\in H^2(\mathbb R^2):M(u)=1,\ \|(\Delta+1)u\|_2^2\le D,\ \|K_1(u)\|_2^2\le B\}\). Define \(R_*(B,D)=\inf_{u\in\mathcal A(B,D)}r_{1/2}(u)\), \(\inf\emptyset=\infty\), with \(r_{1/2}\) defined by the same ball-mass formula as GC90. Determine whether \(R_*(B,D)>0\) when \(\mathcal A(B,D)\ne\emptyset\), and if the infimum is attained modulo translations.
