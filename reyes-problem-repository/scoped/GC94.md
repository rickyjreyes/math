# GC94: Bounded curvature-coupling disorder

**Version:** concrete mathematical target v1 (2026-10-30). **Status:** mathematically proposed, not prior-art-certified or proved. Shared definitions: [COMMON_MODELS](COMMON_MODELS.md). Historical candidate: [GC94](../problems/02-confinement-curvature/GC94.md).

## Exact question

For \(h\in C_c^\infty(\mathbb R^2;\mathbb R)\) with \(\|h\|_\infty\le1\) and \(|\delta|\le1/2\), define \(E_\delta(u)=E_W(u)+\int(1+\delta h(x))|K_1(u)|^2dx\). For mass \(M(u)=m>0\), let \(I_\delta(m)=\inf E_\delta\). Determine the set of \((m,h)\) for which \(I_\delta(m)\) is attained for all sufficiently small \(\delta\) and every sequence of minimizers is precompact modulo translations as \(\delta\to0\).
