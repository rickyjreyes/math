## Exact question

Fix \(R=1\) and observation map \(\mathcal O(u)=(u|_{B_1},K_1(u)|_{B_1})\) on \(C^\infty(\mathbb R^2;\mathbb C)\cap H^2\). Define \(\mathcal L=\{u: \int_{|x|>2}|u|^2\le0.01M(u)\}\). Decide whether there exists a decision function \(D\) of the exact local observation \(\mathcal O(u)\) with \(D(\mathcal O(u))=1\) if and only if \(u\in\mathcal L\), for all nonzero u in the class.
