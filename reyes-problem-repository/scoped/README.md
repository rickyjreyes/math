# Scoped mathematical research dossiers, GC66–GC300

This directory contains **235 expanded working dossiers** for the original GC66–GC300 candidate sketches, with permanent IDs. The source sketches remain unchanged in [the original problem folders](../problems/README.md).

Each dossier links to its historical statement and contains a proposed benchmark equation/operator, explicit choices to quantify, one decisive target, a record of the October 30 scoping objection, possible counterexamples, and a provisional [difficulty estimate](../DIFFICULTY_RUBRIC.md).

**Scientific status:** These are **editorial model proposals**, not completed literature reviews, proofs, Lean formalizations, or verified globally open questions. Some problems have known classical resolutions in their unrestricted form (notably GC197 and GC200). Several topics require additional model fixing, and the critical P0 entries are marked accordingly. Do not cite the dossier as scientific evidence.
